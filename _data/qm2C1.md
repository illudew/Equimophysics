## 核心概念

- **散射（scattering）**：认识微观世界的主要手段；微观粒子结构、性质、运动规律及相互作用的信息一般只有通过碰撞（散射）过程获得。
- **一维散射 / 三维散射**：一维散射只有透射几率和反射几率；三维散射入射粒子被散射后需考虑出射到各不同方向、各不同立体角内的几率。
- **道（channel）**：末态粒子可以多种多样，散射过程可很复杂，由此引入各种入射道、散射道等概念。
- **弹性散射（elastic scattering）**：碰撞中入射粒子与靶粒子只有动量交换，粒子的结构和内部状态均不改变；动量大小 $k$ 不变，一般只有动量方向改变。
- **非弹性散射（inelastic scattering）**：粒子结构不改变，但至少有一个粒子改变内部状态（如激发）；或粒子改变结构，产生数目不定的末态粒子（反应）。能量小时一般只有弹性散射，能量大时可同时出现弹性和非弹性散射。
- **微分散射截面 $\sigma(\theta,\varphi)$**：具有面积量纲，表示每个入射粒子被散射到 $(\theta,\varphi)$ 方向单位立体角内的几率（differential cross section）。
- **总散射截面 $\sigma_T$**：微分散射截面对所有方向积分（cross section）。
- **barn（巴）**：散射截面的常用单位。
- **质心系与实验室系**：角度坐标在质心系中无下标，在实验室系中有下标 lab。
- **折合质量（约化质量）$\mu$**：两体问题可分离为质心自由运动与相对运动，相对运动等价于质量为 $\mu$ 的粒子在质心静止系中受势 $V(r)$ 作用的单粒子运动，$r$ 为相对运动坐标。
- **散射态问题**：已知相互作用势 $V(r)$ 和入射粒子能量 $E>0$，求散射态波函数；无穷远处散射态波函数不为零，其渐近行为决定微分截面大小。
- **散射振幅 $f(\theta,\varphi)$**：由散射势 $V(r)$ 决定，其模方给出微分截面。
- **轨道角动量守恒**：在中心势场 $V(r)$ 中运动的粒子轨道角动量守恒，$L^2$、$L_z$ 都与哈密顿量 $H$ 对易，具有共同完备本征函数系。
- **分波**：与 $l=0,1,2,\dots$ 对应的分波分别称为 s、p、d…… 分波；中心势散射中，不同轨道角动量量子数 $l$ 的分波波函数各自彼此独立地散射。
- **分波相移 $\delta_l$**：$\delta_l$ 为入射平面波第 $l$ 分波位相 $kr-\dfrac{l\pi}{2}$ 与总散射波函数第 $l$ 分波位相 $kr-\dfrac{l\pi}{2}+\delta_l$ 之差，与散射势 $V(r)$ 有关。
- **相移的物理意义**：相移不太大时，相移符号与势的符号相反——吸引势 $V(r)<0$ 对应 $\delta_l>0$；排斥势 $V(r)>0$ 对应 $\delta_l<0$。
- **球谐函数 $Y_{lm}(\theta,\varphi)$**：$L^2$ 与 $L_z$ 的共同本征函数系。
- **球贝塞尔函数 / 球诺伊曼函数 / 勒让德多项式**：分波展开与径向方程求解中使用的特殊函数。
- **玻恩近似**：入射能量较高时用 $u_l\approx f_l=\rho j_l(\rho)$ 估计相移，得到散射振幅近似公式。
- **光学定理**：普遍成立的关系 $\sigma=\dfrac{4\pi}{k}\operatorname{Im}f(0)$，可简化计算；物理意义是散射区域后方粒子流强度比入射流强小，前后流强差值正比于总散射截面。
- **分波法适用条件**：短程势作用范围 $a$，仅需叠加 $l=0$ 到 $l_{\max}=ka$ 的分波；低能时 $ka\ll1$ 只需计算 s 波散射。
- **散射长度 $a$** 与 **有效力程 $r_{\text{eff}}$**：低能散射实验数据常用它们表示；有效力程反映 s 波相移 $\delta_0$ 与入射能量 $E$ 的关系。
- **刚球势散射**：低能极限下总截面约为 $4\pi a^2$（经典情况下为 $\pi a^2$，即量子结果为经典值的四倍），仅空间各向同性 s 波有贡献。
- **库仑势散射**：$V_C(r)$ 为中心势场，散射前后轨道角动量守恒，分波求和适用；但 $r\to\infty$ 时存在对数型相位，径向波函数不趋于正弦函数，相移意义完全不同。
- **抛物线坐标（旋转抛物面坐标）**：求解纯库仑势束缚态或散射态问题时使用较方便。
- **Γ 函数（第二类欧拉积分）/ 合流超几何函数 $W(a,c,z)$**：归一化库仑波函数的表示及分波解所需特殊函数。
- **库仑相移 $\delta_l^C$**：由 Γ 函数比值定义，$\delta_l^C=\dfrac{1}{2i}\ln\dfrac{\Gamma(l+1+i\gamma)}{\Gamma(l+1-i\gamma)}=\arg\Gamma(l+1+i\gamma)$。
- **库仑势与短程势叠加**：一般只有前几个分波发生改变；散射振幅可分解为库仑散射振幅与短程势附加振幅之和，并有扭曲波近似、格劳伯（Glauber）理论等处理方法。

## 重要公式

**第一章 散射过程的物理描述**

- **立体角元**： `dΩ = sinθ dθ dφ`
- **微分截面定义**： `dn = σ(θ,φ) N dΩ`
- **总散射截面**： `σ_T = ∫σ(θ,φ)dΩ = ∫₀^{2π}dφ ∫₀^{π}sinθ dθ σ(θ,φ)`
- **截面单位**： `1 barn = 10^{-24} cm² = 10^{-28} m²`
- **实验室系与质心系出射角关系**： `tanθ_{lab} = sinθ/(cosθ+γ),  φ_{lab}=φ（γ = m_A/m_B）`
- **两参考系微分截面关系**： `σ(θ_{lab},φ_{lab}) = [(1+2γcosθ+γ²)^{3/2}/(1+γcosθ)]·σ(θ,φ)`
- **非弹性散射的 γ**： `γ = [(m_A m_A′/(m_B m_B′))·(E/(E+Q))]^{1/2}`
- **实验室系哈密顿量算符**： `H(r_A,r_B) = -(ħ²/2m_A)∇_A² - (ħ²/2m_B)∇_B² + V(r_A-r_B)`
- **相对坐标与质心坐标**： `r = r_A - r_B,  R = (m_A r_A + m_B r_B)/(m_A+m_B)`
- **折合质量**： `μ = m_A m_B/(m_A+m_B)`
- **动能算符的分离**： `-(ħ²/2m_A)∇_A² - (ħ²/2m_B)∇_B² = -(ħ²/2μ)∇_r² - (ħ²/2(m_A+m_B))∇_R²`
- **质心系哈密顿量**： `H(r) = -(ħ²/2μ)∇² + V(r)`
- **质心系入射动能**： `E = ħ²k²/2μ = [m_B/(m_A+m_B)]E_{lab} = [1/(1+γ)]E_{lab}`
- **梯度算符球坐标形式**： `∇ = e_x∂/∂x+e_y∂/∂y+e_z∂/∂z = e_r∂/∂r + e_θ(1/r)∂/∂θ + e_φ(1/(r sinθ))∂/∂φ`
- **定态薛定谔方程**： `[-(ħ²/2μ)∇² + V(r)]ψ(r) = Eψ(r)`；改写为 `∇²ψ(r) + [k² - U(r)]ψ(r) = 0`
- **U(r) 与 k² 定义**： `U(r) = (2μ/ħ²)V(r),  k² = (2μ/ħ²)E`
- **渐近波函数**： `ψ_A(r) = e^{ikz} + f(θ,φ)·e^{ikr}/r`
- **入射粒子流密度**： `N = ħk/μ ≡ v`
- **概率流密度算符**： `J = (ħ/2μi)(ψ*∇ψ - ψ∇ψ*)`；渐近区仅保留径向分量 `J_r = v|f(θ,φ)|²/r²`
- **散射到 dS 内的粒子数**： `dn = J·dS = J_r·(r²dΩ) = v|f(θ,φ)|²dΩ = N|f(θ,φ)|²dΩ`
- **微分散射截面与散射振幅**： `σ(θ,φ) = |f(θ,φ)|²`
- **总散射截面**： `σ = ∫₀^{2π}dφ ∫₀^{π}sinθ dθ |f(θ,φ)|²`

**第二章 分波法（一）**

- **轨道角动量算符**： `L = r × p = r × (-iħ∇)`
- **对易关系**： `[L_α, x_β] = iħ ε_{αβγ}x_γ,  [L_α, p_β] = iħ ε_{αβγ}p_γ,  [L_α, L_β] = iħ ε_{αβγ}L_γ（即 L×L = iħL）`
- **其它对易关系**： `[L², L_α] = 0;  [L, r²] = 0, [L, p²] = 0, [L, r·p] = 0, [L, V(r)] = 0`
- **动能算符与轨道角动量**： `T = p²/2μ = -(ħ²/2μ)∇² = -(ħ²/2μ)(1/r²)(d/dr)(r² d/dr) + L²/(2μr²)`
- **L² 的球坐标形式**： `L² = -ħ²[ (1/sinθ)∂/∂θ(sinθ ∂/∂θ) + (1/sin²θ)∂²/∂φ² ]`
- **L²、L_z 本征方程**： `L²Y_{lm} = ħ²l(l+1)Y_{lm},  L_zY_{lm} = mħY_{lm}  (l=0,1,2,…; m=l,l-1,…,−l)`
- **球谐函数归一化**： `∫₀^{2π}dφ ∫₀^{π}sinθ dθ Y_{l′m′}*(θ,φ)Y_{lm}(θ,φ) = δ_{ll′}δ_{mm′}`
- **中心势径向方程（R_l）**： `(1/r²)(d/dr)(r² dR_l/dr) + [k² - l(l+1)/r² - U(r)]R_l = 0`
- **分波求和形式**： `ψ(r) = Σ_{l=0}^∞ R_l(r)P_l(cosθ)`（入射沿极轴，m=0）
- **u_l = rR_l 的方程**： `d²u_l/dr² + [k² - l(l+1)/r² - U(r)]u_l = 0,  边界条件 u_l(0)=0`
- **径向波函数渐近解**： `u_l^A(r) = (A_l/k) sin(kr - lπ/2 + δ_l)`
- **散射波函数渐近形式**： `ψ^A(r,θ) = Σ_{l=0}^∞ (A_l/(kr)) sin(kr - lπ/2 + δ_l) P_l(cosθ)`
- **平面波展开（瑞利展开）**： `e^{ikz} = e^{ikr cosθ} = Σ_{l=0}^∞ (2l+1)i^l j_l(kr)P_l(cosθ)`
- **球贝塞尔函数渐近行为**： `j_l(kr) → (1/kr) sin(kr - lπ/2)  (r→∞)`
- **系数确定**： `A_l = (2l+1)i^l e^{iδ_l}`
- **散射振幅的分波展开**： `f(θ) = (1/k)Σ_{l=0}^∞ (2l+1) e^{iδ_l} sinδ_l P_l(cosθ)`
- **相移与势的关系**： `sinδ_l = -∫₀^∞ [V(ρ/k)/E] f_l(ρ)u_l(ρ)dρ`（其中 ρ=kr，f_l(ρ)=ρj_l(ρ)）
- **相移符号规律**： 吸引势 `V(r)<0 ⇔ δ_l>0`；排斥势 `V(r)>0 ⇔ δ_l<0`
- **玻恩近似相移**： `sinδ_l ≈ -(2μ/ħ²)k ∫₀^∞ V(r) j_l²(kr) r²dr`
- **散射振幅（小相移）**： `f(θ) ≈ Σ_{l}(2l+1)(δ_l/k)P_l(cosθ) ≈ -(2μ/ħ²)∫₀^∞V(r)r²dr Σ_l(2l+1)P_l(cosθ)j_l²(kr)`
- **恒等式**： `sin(qr)/(qr) = Σ_{l=0}^∞ (2l+1)P_l(cosθ) j_l²(kr)`
- **中心势散射玻恩近似公式**： `f(θ) = -(2μ/ħ²q) ∫₀^∞ V(r) sin(qr) r dr`

**第二章 分波法（二）**

- **微分散射截面**： `σ(θ) = |f(θ)|² = (1/k²)|Σ_{l=0}^∞ (2l+1)e^{iδ_l}sinδ_l P_l(cosθ)|²`
- **总散射截面（分波求和）**： `σ = (4π/k²)Σ_{l=0}^∞ (2l+1) sin²δ_l`
- **各分波截面**： `σ = Σ_l σ_l,  σ_l = (4π/k²)(2l+1) sin²δ_l`
- **光学定理**： `σ = (4π/k) Im f(0)`（θ=0 时 P_l(1)=1）
- **碰撞参数与角动量**： `L = pb = ħkb = ħ√(l(l+1)) ≈ lħ`
- **求和上限**： `l_max = ka`（仅叠加 l=0 到 l_max 的分波）
- **质子-质子散射估计**： `1/k ≈ 4.5/√(E/MeV) fm`（核力作用范围 a≈1 fm）
- **低能方势阱总截面**： `σ = (4π/k²)sin²δ_0 ≈ (4π/k²)tan²δ_0 ≈ 4πa²[tan(k_0a)/(k_0a) - 1]²`
- **低能方势垒总截面**： `σ ≈ 4πa²[tanh(κ_0a)/(κ_0a) - 1]²,  κ_0 ≡ √(2μ/ħ² · V_1)`
- **方势垒相移**： `tanδ_0 ≈ ka[tanh(κ_0a)/(κ_0a) - 1]`
- **低能方势阱相移**： `tanδ_0 ≈ ka[tan(k_0a)/(k_0a) - 1],  k_0 ≡ √(2μ/ħ² · V_0)`
- **刚球势总截面（低能）**： `σ ≈ 4πa²`
- **刚球势总截面（高能）**： `σ = 2πa²[1 + 0.99615/(ka)² + …]`
- **散射长度定义**： `a = -lim_{k→0} tanδ_0(k)/k`
- **低能散射截面与散射长度**： `lim_{k→0} σ_0 = 4πa²`
- **有效力程定义**： `r_{eff} ≡ 2∫₀^∞ (v_0² - u_0²)dr |_{k→0}`
- **有效力程展开**： `k cotδ_0(k) = -1/a + (1/2)r_{eff}k² + …`
- **s 波散射截面**： `σ_0 = (4π/k²)sin²δ_0 ≈ 4π/[k² + (1/a - (1/2)r_{eff}k²)²]`
- **方势阱散射长度**： `a ≈ -d[tan(k′d)/(k′d) - 1] ≈ d[1 - tan(k_0d)/(k_0d)]`
- **方势垒散射长度**： `a ≈ -d[tan(k′d)/(k′d) - 1] ≈ d[1 - tanh(κ_0d)/(κ_0d)]`
- **低能 s 波径向波函数极限**： `lim_{k→0}(sin kr·cotδ_0 + cos kr) ≈ 1 - r/a`
- **有效力程公式成立条件**： 势须足够快趋于零（若 `V(r) ∝ r^{-m}`，则要求 `m > 5`）；方势阱（作用范围 d）有 `r_{eff} = d`

**第三章 库仑势散射**

- **库仑势**： `V_C(r) = (1/4πε_0)(Z_1Z_2e²/r) = Z_1Z_2αħc/r`
- **精细结构常数**： `α = e²/(4πε_0ħc)`
- **自然单位制**： `V_C(r) = Z_1Z_2α/r,  α = e²/4π`
- **渐近行为（对数型相位）**： `u_l^A(r) ∝ e^{±i(kr - n ln r)}  (r→∞),  n = μZ_1Z_2e²/(4πε_0ħ²k) = Z_1Z_2e²/(4πε_0ħ v)`
- **抛物线坐标**： `ξ = r - z = r(1-cosθ),  η = r + z = r(1+cosθ),  φ = φ`
- **库仑定态薛定谔方程**： `(∇² + k² - 2γk/r)ψ_C(r) = 0,  k² = (2μ/ħ²)E,  γ = μZ_1Z_2αc/k = Z_1Z_2αc/v`
- **归一化库仑波函数**： `ψ_C(r) = e^{-πγ/2} Γ(1+iγ) e^{ikz} W[-iγ, 1, ik(r-z)]`
- **库仑波函数分波展开**： `ψ_C(r,θ) = Σ_{l=0}^∞ 4π(2l+1) i^l (u_l^C(r)/kr) P_l(cosθ)`
- **库仑径向方程**： `[d²/dr² + k² - 2kγ/r - l(l+1)/r²]u_l^C(r) = 0`
- **正则/非正则库仑波函数渐近形式**：
  `F_l(r) → sin(kr - γln2kr - lπ/2 + δ_l^C),  G_l(r) → cos(kr - γln2kr - lπ/2 + δ_l^C)  (r→∞)`
- **库仑散射相移**： `δ_l^C = (1/2i) ln[Γ(l+1+iγ)/Γ(l+1-iγ)] = argΓ(l+1+iγ)`
- **库仑散射振幅**：
  `f_C(θ) = (1/2ik)Σ_{l=0}^∞ (2l+1)(e^{2iδ_l^C}-1)P_l(cosθ)`
  `= -γ/(2k sin²(θ/2)) · [Γ(1+iγ)/Γ(1-iγ)] · exp{-iγ ln[sin²(θ/2)]}`
- **库仑散射微分截面（卢瑟福公式）**： `σ_C(θ) = |f_C(θ)|² = [Z_1Z_2e²/(4πε_0·4E)]² · 1/sin⁴(θ/2)`（即经典卢瑟福公式）
- **两势叠加径向方程**： `[d²/dr² + k² - 2kγ/r - U(r) - l(l+1)/r²]u_l(r) = 0`
- **两势叠加渐近形式**： `u_l(r) → A_l[e^{-i(kr - γln2kr)} - e^{2i(δ_l^C + δ_l^n)} e^{i(kr - γln2kr - lπ)}]`（δ_l^n 为短程势引起的附加相移）
- **散射振幅分解**： `f(θ) = f_C(θ) + f_n(θ)`，其中 `f_n(θ) = (1/2ik)Σ_l (2l+1)(e^{2iδ_l^C}e^{2iδ_l^n}-1)P_l(cosθ)`
- **微分散射截面**： `σ(θ) = |f_C + f_n|² = |f_C|² + |f_n|² + 2Re[f_C* f_n]`
- **含库仑势的有效力程**： `r_{eff}^C ≡ 2∫₀^∞(v_0² - u_0²)dr |_{k→0}`
- **低能 s 波相移与 k 的关系**：
  `2γk[ (π cotδ_0^n(k))/(e^{2πγ}-1) + η(γ) ] = -1/a + (1/2)r_{eff}^C k² + …`
- **η(γ) 定义**： `η(γ) = Σ_{n=1}^∞ γ²/[n(n²+γ²)] - lnγ - C`（C 为欧拉常数）
- **Γ 函数**： `Γ(a) = ∫₀^∞ x^{a-1}e^{-x}dx (a>0),  Γ(a+1)=aΓ(a),  Γ(n+1)=n!,  Γ(1/2)=√π,  Γ(a)Γ(1-a)=π/sin(πa)`
- **合流超几何方程**： `z d²y/dz² + (c-z)dy/dz - a y = 0`，正则解 `W(a,c,z)`，非正则解 `z^{1-c}W(a+1-c,2-c,z)`
- **合流超几何函数积分表示**： `W(a,c,z) = [Γ(c)/(Γ(a)Γ(c-a))] ∫₀^1 e^{zt} t^{a-1}(1-t)^{c-a-1}dt`
- **合流超几何函数渐近行为**： `W(a,c,z) → [Γ(c)/Γ(a)] z^{a-c}e^z + [Γ(c)/Γ(c-a)] z^{-a}e^{±iπa}  (z→∞)`
