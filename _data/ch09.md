## 核心概念
- **黑体辐射与普朗克公式**：普朗克通过假设谐振子能量分立 $E=nhf$、跃迁放能 $\Delta E=hf$，得到与实验相符的黑体谱，标志量子论诞生。
- **光电效应与光子**：光以能量子（光子）$E=h\nu$ 形式与物质作用，$h\nu=\phi+E_k$。
- **康普顿效应**：光子与静止自由电子弹性碰撞，散射光子波长变长，$\lambda'-\lambda=\frac{h}{m_ec}(1-\cos\theta)$。
- **物质波（德布罗意关系）**：$\lambda=h/p$。
- **概率密度与连续性方程**：$P=|\psi|^2$，概率守恒写作 $\partial P/\partial t+\nabla\cdot J=0$。
- **狄拉克符号（Dirac notation）**：用 ket $|\psi\rangle$、bra $\langle\psi|$ 及标积（bracket）$\langle\phi|\psi\rangle$ 抽象地表示量子态与内积。
- **可观测量与线性算符**：可观测量 $A$ 用算符 $\hat{A}$ 表示，$\hat{A}|\psi\rangle=|\varphi\rangle$。
- **厄米共轭与厄米算符**：$\hat{A}^{\dagger}=\hat{A}$ 为厄米（自伴）算符，其本征值全为实数、不同本征值对应的本征矢正交。
- **对易子（commutator）**：$[\hat{A},\hat{B}]=\hat{A}\hat{B}-\hat{B}\hat{A}$，满足反对称性、线性、分配律等；两算符对易当且仅当 $[\hat{A},\hat{B}]=0$。
- **不确定度关系（Heisenberg）**：$\Delta A\,\Delta B\ge\frac{1}{2}|\langle[\hat A,\hat B]\rangle|$，位置—动量给出 $\Delta x\Delta p_x\ge\hbar/2$。
- **本征值与本征矢**：$\hat{A}|n\rangle=a_n|n\rangle$；厄米算符本征值为实、本征矢正交归一。
- **矩阵表示与表象**：算符在基 $\{|n\rangle\}$ 下表示为矩阵 $A_{nm}=\langle n|\hat{A}|m\rangle$。
- **位置与动量表象**：位置本征态构成连续基，波函数是态矢量在位置表象的分量；两表象由傅里叶变换联系。
- **时间演化与传播子**：态按 $\hat{U}(t,t_0)=e^{-\frac{i}{\hbar}\hat H(t-t_0)}$ 演化。
- **埃伦费斯特定理（Ehrenfest's theorem）**：量子力学中算符期望值满足与经典运动方程相同的形式，$\frac{d\langle\hat A\rangle}{dt}=\frac{1}{i\hbar}\langle[\hat A,\hat H]\rangle$。
- **自由粒子**：能谱连续，$\psi(x,t)=A^{(+)}e^{i(kx-\omega t)}+A^{(-)}e^{-i(kx+\omega t)}$。
- **无限深势阱**：束缚态能量分立，$E_n=\dfrac{n^2\pi^2\hbar^2}{2ma^2}$。
- **间断势/δ 势/有限深势阱**：波函数在有限跳变处连续，一阶导数在 δ 势处有跳变；有限深阱束缚态数目有限。
- **谐振子（代数解法）**：引入升降算符 $a,\ a^{\dagger}$，$[a,a^{\dagger}]=1$，能量 $E_n=(n+\frac12)\hbar\omega$，存在零点能。
- **势垒反射与透射系数**：$R=\dfrac{J_R}{J_I}$、$T=\dfrac{J_T}{J_I}$，且 $R+T=1$。
- **周期势与布洛赫定理（Bloch）**：周期势中能量形成能带与带隙，$\psi(x+c)=e^{iKc}\psi(x)$。
- **轨道角动量**：$\hat{\vec L}=\hat{\vec r}\times\hat{\vec p}$，满足 $[\hat L_i,\hat L_j]=i\hbar\varepsilon_{ijk}\hat L_k$。
- **升降算符（ladder operator）**：$\hat L_{\pm}=\hat L_x\pm i\hat L_y$，$[\hat L_z,\hat L_{\pm}]=\pm\hbar\hat L_{\pm}$，$[\hat L^2,\hat L_{\pm}]=0$。
- **球谐函数（spherical harmonics）**：$\hat L^2$ 与 $\hat L_z$ 的共同本征函数 $Y_l^m(\theta,\phi)$，本征值为 $\hbar^2 l(l+1)$ 与 $m\hbar$。
- **角动量矩阵表示**：在 $l=1$ 基下给出 $\hat L_z,\hat L_\pm,\hat L_x,\hat L_y$ 的矩阵。
- **斯特恩–格拉赫实验与自旋**：原子束在非均匀磁场中分裂，说明存在自旋角动量；自旋算符满足与轨道角动量相同的对易关系。
- **泡利矩阵（Pauli matrices）**：描述自旋 1/2 的 $2\times2$ 矩阵 $\hat\sigma_x,\hat\sigma_y,\hat\sigma_z$，反对易 $\{\hat\sigma_i,\hat\sigma_j\}=0$（$i\neq j$）。
- **角动量相加**：$\hat{\vec J}=\hat{\vec L}+\hat{\vec S}$，$j$ 取值 $|l-s|\le j\le l+s$。
- **三维分离变量**：当 $V=V_1(x)+V_2(y)+V_3(z)$ 时，$\psi=X(x)Y(y)Z(z)$，三维问题化为一维。
- **三维无限深势阱（方形/立方）**：$E_{n_1n_2n_3}=\frac{\hbar^2\pi^2}{2m}\left(\frac{n_1^2}{a^2}+\frac{n_2^2}{b^2}+\frac{n_3^2}{c^2}\right)$。
- **氢原子**：球坐标下径向方程可解，能级 $E_n=-\frac{\mu e^4}{(4\pi\varepsilon_0)^2 2\hbar^2}\frac{1}{n^2}$，简并度 $g=n^2$。
- **各向同性谐振子**：三维各向同性振子能级 $E=(\frac32+n)\hbar\omega$，波函数为三个一维振子波函数之积。
- **可分辨粒子体系**：$N$ 个可分辨粒子的波函数为单粒子波函数之积，总能量为各单粒子能量之和。
- **全同粒子与交换对称性**：全同粒子波函数在交换任意两粒子时只能对称（玻色子）或反对称（费米子）。
- **泡利不相容原理**：费米子体系总波函数反对称，$N$ 粒子反对称波函数写成 Slater 行列式。
- **定态（非简并）微扰论**：能量与波函数的一阶、二阶修正。
- **简并微扰论**：由久期行列式 $\det(h_{ij}-E^{(1)}\delta_{ij})=0$ 确定一阶能量分裂。
- **变分法（variation method）**：对归一化试探波函数 $\langle H\rangle=\langle\phi|\hat H|\phi\rangle\ge E_g$，通过调节变分参数取极小得基态能量上界。
- **Hartree–Fock 近似**：把多电子波函数取为 Slater 行列式并对单粒子轨道变分得到的方程，含直接项与交换项。
- **含时微扰论**：态按未微扰本征态展开，$c_m(t)$ 满足耦合方程组，一阶修正与 $\langle m|H_1|n\rangle$ 有关。
- **散射截面与玻恩近似**：微分截面 $\frac{d\sigma}{d\Omega}=\frac{J_{sc}}{J_{inc}}$；弱势下一阶玻恩近似把散射振幅写成势的傅里叶变换。
- **分波分析**：把散射振幅按分波（角动量本征态）展开处理。

## 重要公式
- **普朗克黑体辐射公式**： `u(f,T) = \frac{8\pi h f^{3}}{c^{3}}\frac{1}{e^{hf/k_BT}-1}`
- **谐振子能量量子化**： `E_{\text{resonator}} = nhf,\quad \Delta E = hf`
- **光电效应方程**： `\tfrac{1}{2}mv_{\max}^{2} = eV_0 = h\nu - \phi = h(\nu-\nu_0)`
- **康普顿散射**： `\lambda' - \lambda = \frac{h}{m_ec}(1-\cos\theta)`
- **德布罗意关系**： `\lambda = \frac{h}{p}`
- **薛定谔方程（自由粒子/含势）**： `-\frac{\hbar^{2}}{2m}\nabla^{2}\psi + V(r)\psi = i\hbar\frac{\partial\psi}{\partial t}`
- **连续性方程**： `\frac{\partial P}{\partial t} + \nabla\cdot J = 0,\qquad P=|\psi|^{2},\qquad J = \frac{i\hbar}{2m}(\psi\nabla\psi^{*}-\psi^{*}\nabla\psi)`
- **标积（bracket）**： `\langle\phi|\psi\rangle = \sum_{i}\phi_i^{*}\psi_i = \int \phi^{*}(r)\psi(r)\,d^{3}r`
- **厄米共轭**： `\langle\psi|\hat A^{\dagger}|\phi\rangle = \langle\phi|\hat A|\psi\rangle^{*}`
- **对易子定义与坐标—动量对易关系**： `[\hat A,\hat B]=\hat A\hat B-\hat B\hat A,\qquad [\hat X,\hat P_x]=i\hbar\hat I`
- **不确定度关系**： `\Delta A\,\Delta B \ge \frac{1}{2}\big|\langle[\hat A,\hat B]\rangle\big|,\qquad \Delta x\,\Delta p_x \ge \frac{\hbar}{2}`
- **本征方程**： `\hat A|n\rangle = a_n|n\rangle,\qquad A_{nm} = \langle n|\hat A|m\rangle`
- **时间演化算符（传播子）**： `|\psi(t)\rangle = \hat U(t,t_0)|\psi(t_0)\rangle,\qquad \hat U(t,t_0) = e^{-\frac{i}{\hbar}\hat H(t-t_0)}`
- **埃伦费斯特定理**： `\frac{d\langle\hat A\rangle}{dt} = \frac{1}{i\hbar}\big\langle[\hat A,\hat H]\big\rangle`
- **自由粒子态**： `\psi(x,t) = A^{(+)}e^{i(kx-\omega t)} + A^{(-)}e^{-i(kx+\omega t)},\qquad E=\hbar^2 k^2/2m`
- **一维无限深势阱**： `\psi_n(x,t) = \sqrt{\frac{2}{a}}\,\sin\!\frac{n\pi x}{a}\,e^{-iE_nt/\hbar},\qquad E_n = \frac{n^{2}\pi^{2}\hbar^{2}}{2ma^{2}}`
- **谐振子能级（代数法）**： `\hat H = \hbar\omega\Big(\hat a^{\dagger}\hat a + \tfrac12\Big),\qquad [\hat a,\hat a^{\dagger}]=1,\qquad E_n = \big(n+\tfrac12\big)\hbar\omega`
- **反射与透射系数**： `R = \frac{J_R}{J_I} = \frac{|B|^{2}}{|A|^{2}},\qquad T = \frac{J_T}{J_I},\qquad R+T=1`
- **布洛赫定理**： `\psi(x+c) = e^{iKc}\psi(x)`
- **角动量对易关系**： `[\hat L_x,\hat L_y] = i\hbar\hat L_z,\quad [\hat L_y,\hat L_z] = i\hbar\hat L_x,\quad [\hat L_z,\hat L_x] = i\hbar\hat L_y,\qquad [\hat L^{2},\hat L_{\pm}]=0`
- **升降算符与球谐函数本征值**： `\hat L_{\pm} = \hat L_x \pm i\hat L_y,\qquad \hat L^{2}Y_l^{m} = \hbar^{2}l(l+1)Y_l^{m},\qquad \hat L_zY_l^{m} = m\hbar Y_l^{m}`
- **自旋对易关系与泡利矩阵**： `[\hat S_x,\hat S_y]=i\hbar\hat S_z,\qquad \{\hat\sigma_i,\hat\sigma_j\}=2\delta_{ij}`
- **三维无限深方形势阱能级**： `E_{n_1n_2n_3} = \frac{\hbar^{2}\pi^{2}}{2m}\left(\frac{n_1^{2}}{a^{2}}+\frac{n_2^{2}}{b^{2}}+\frac{n_3^{2}}{c^{2}}\right)`
- **氢原子能级与简并度**： `E_n = -\frac{\mu e^{4}}{2(4\pi\varepsilon_0)^{2}\hbar^{2}}\frac{1}{n^{2}},\qquad g = \sum_{l=0}^{n-1}(2l+1) = n^{2}`
- **Slater 行列式（反对称波函数）**： `\phi_a(\xi_1,\dots,\xi_N) = \frac{1}{\sqrt{N!}}\det\!\big[\varphi_{n_i}(\xi_j)\big]`
- **定态微扰（一阶/二阶能量）**： `E_n^{(1)} = \langle\psi_n^{(0)}|H_1|\psi_n^{(0)}\rangle,\qquad E_n^{(2)} = \sum_{m\neq n}\frac{|\langle\psi_m^{(0)}|H_1|\psi_n^{(0)}\rangle|^{2}}{E_n^{(0)}-E_m^{(0)}}`
- **简并微扰久期方程**： `\det\big(h_{ij} - E^{(1)}\delta_{ij}\big) = 0,\qquad h_{ij}=\langle\psi_{n_i}^{(0)}|H_1|\psi_{n_j}^{(0)}\rangle`
- **变分原理**： `E_g \le \langle H\rangle = \frac{\langle\phi|\hat H|\phi\rangle}{\langle\phi|\phi\rangle}`
- **含时微扰一阶振幅**： `c_m^{(1)}(t) = \frac{1}{i\hbar}\sum_{n}\int h_{mn}(t')\,c_n^{(0)}(t')\,e^{i\omega_{mn}t'}\,dt',\qquad h_{mn}=\langle\varphi_m|H_1|\varphi_n\rangle`
- **散射微分截面**： `\frac{d\sigma}{d\Omega} = \frac{J_{sc}}{J_{inc}} = |f(\theta)|^{2}`
- **一阶玻恩近似散射振幅**： `f^{(1)}(\theta) = -\frac{1}{4\pi}\frac{2m}{\hbar^{2}}\int e^{-i\vec q\cdot\vec r'}\,V(\vec r')\,d^{3}r'`

## 常见考法（推断）
- 计算对易关系（如 $[\hat L_x,\hat L_y]$、$[\hat J_z,\hat J_{\pm}]$、$[\hat J_+,\hat J_-]$），并据此判断算符是否可同时测量。
- 算符本征值问题：给定哈密顿量（或某算符）的矩阵表示，求本征值与对应本征态，再求某观测量在能量基态下的期望值与不确定度。
- 由态在完备基下的展开系数，求含时演化 $\psi(t)$、各能量本征值的概率、$L_z$ 的期望值及其概率分布。
- 一维无限深方势阱：由初态归一化系数求能量取值及概率、写出 $\Psi(x,t)$；并讨论概率是否守恒。
- 微扰论：无限深势阱（或谐振子）加微扰，求基态能量的二阶修正与波函数的一阶修正；简并/非简并情形的久期方程。
- 自旋体系：给定自旋哈密顿量（如 $H=a(S_x^{(1)}S_x^{(2)}+S_y^{(1)}S_y^{(2)}-S_z^{(1)}S_z^{(2)}$），求能量本征值与简并度，并计算自旋翻转几率。
- 全同粒子与泡利原理：写出费米子体系的反对称（Slater 行列式）波函数、玻色子体系的对称波函数，并求基态/第一激发态能量。
- 角动量相加与氢原子：由轨道角动量大小 $\sqrt{l(l+1)}\hbar$ 确定 $l$，写出氢原子概率密度 $P(r)dr$ 与 $L_z$ 期望值。
