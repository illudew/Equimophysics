## 核心概念

**课程介绍 / 总览**
- **高等量子力学**：在本科量子力学基础上的提高课程，系统讨论希尔伯特空间、薛定谔方程与时间演化、算符与表象、二次量子化、相对论量子力学及量子信息等专题。

**第 1 章 希尔伯特空间**
- **希尔伯特空间**：一个抽象的（复）矢量空间，其上定义的内积使距离、角度可测量；把三维欧几里德空间的矢量代数推广到有限维或无穷维。定义在复平面上，是完备的复内积空间。
- **内积**：按一定次序取两个矢量 ψ 和 ϕ 得到一个数 c，记为 ⟨ψ, ϕ⟩ = c；实（复）矢量空间中的内积为实数（复数）。
- **实内积三条件**：对称性、线性、正定（⟨x, x⟩ ≥ 0，当且仅当 x = 0 时等号成立）。
- **矢量空间（线性空间）**：具有加法与数乘两种运算并满足条件 (1)–(8) 的集合；具有加法、数乘和内积三种运算的空间称为内积空间；完全的内积空间称为希尔伯特空间。
- **零矢量唯一性 / 负矢量唯一性**：空间中的零矢量、每个矢量的负矢量都是唯一的（可由公理证明）。
- **正交**：两个矢量的内积为零，即 ⟨ψ, ϕ⟩ = 0。
- **模方与模**：⟨ψ, ψ⟩ 是不小于零的实数，称模方，记为 |ψ|²；其正平方根为模 |ψ|（即矢量长度）；模等于 1 的矢量称归一化矢量。
- **Cauchy-Schwartz 不等式**：对任意矢量 ψ、ϕ 成立。
- **三角形不等式**：对任意矢量 ψ、ϕ 成立。
- **线性无关**：有限个矢量 {ψᵢ} 只有当全部系数 aᵢ 都为零时 Σᵢ ψᵢaᵢ = 0 才成立；否则为线性相关（不含零矢量的线性相关组中任一矢量可表为其余矢量的线性叠加）。对无穷集合，若任意有限子集合都线性无关，则整个集合线性无关。
- **完全集（Complete set）**：线性无关且空间中每个矢量都能表为其线性叠加的矢量集合 {λᵢ}。
- **维度**：有限维空间中各种不同完全集所含矢量数目相同，这个数目称为空间的维度。「有限维 / 无穷维」取决于能否通过扩充得到完全集。
- **基矢**：正交归一的完全集；空间可有不同的多组基矢。
- **Schmidt 正交化方法**：只要知道一个完全集，总可通过逐步归一化、扣除投影的方法构造出一组正交归一基矢。
- **四个等价命题**：若 {vᵢ}（i = 1,…,n）是一组 n 个正交归一矢量，则「{vᵢ} 是基」「ψ = Σᵢ vᵢ⟨vᵢ, ψ⟩」「⟨ϕ, ψ⟩ = Σᵢ⟨ϕ, vᵢ⟩⟨vᵢ, ψ⟩」「|ψ|² = Σᵢ|⟨vᵢ, ψ⟩|²」对一切态成立，四者相互等价（分别对应完备性、态展开、内积分解、Parseval 关系）。
- **右矢与左矢（狄拉克记号）**：作为右因子的矢量记为 |ϕ⟩，作为左因子的记为 ⟨ψ|，内积记为 ⟨ψ|ϕ⟩。内积对右因子线性、对左因子反线性；故同一矢量作为右/左因子地位不同。左矢空间与右矢空间通过内积四条件相协调。

**第 2 章 态和薛定谔方程**
- **德布罗意物质波**：与能量 E、动量 p 的粒子相联系的波，频率与波长分别为 ν = E/h、λ = h/p；据驻波条件可解释角动量量子化。
- **波粒二象性**：双缝干涉实验证实波动性；which-way 实验表明可判断路径时干涉花纹消失。单个电子既具粒子性又具波动性，不同于经典粒子与经典波。
- **波恩概率诠释**：波函数的模方对应粒子出现的概率密度；图样强度 ∝ 感光点数目 ∝ 粒子数 ∝ 出现概率。
- **归一化与相对概率**：粒子在空间出现的概率总和为 1；对概率分布重要的是相对概率分布，ψ(x) 与 Cψ(x) 描述相同的相对概率分布。
- **统计诠释对波函数的要求**：任何有限体积元内找到粒子的概率为有限值；满足归一化条件。
- **态的叠加原理**：波函数描述量子态，波的相干叠加意味着态的叠加；波包可看作多个具有确定动量本征态的线性叠加，各本征态以确定概率出现。
- **不确定关系**：坐标与动量不能同时具有确定值；由 ΔA、ΔB 的一般不等式得到，是微观粒子波动性的表现。
- **薛定谔方程**：1926 年提出，解决波函数随时间演化问题；是不含时、非相对论量子力学的基本方程（低能下粒子数守恒）。
- **概率守恒与概率流密度**：概率密度 ρ 随时间变化满足连续性方程，全空间概率总和不随时间改变。
- **不含时薛定谔方程**：势场不显含时间时波函数可分离变量，得系统本征方程；满足物理要求的解对应的能量 E 称为本征能量；定态的演化带有动力学相位因子 e^{−iEt/ħ}。
- **定态与非定态**：本征态（定态）下概率密度与力学量平均值不随时间变化；本征态叠加态（非定态）下概率密度不变而力学量平均值随时间变化。
- **零点能**：一维无限深方势阱最低能级 E₁ ≠ 0，是微观粒子波动性（不确定关系）的表现。
- **算符**：代表对波函数（量子态）的一种运算；力学量（可观测量）算符都是线性算符，满足态的叠加原理。
- **厄米算符**：满足 A† = A（或 ⟨ϕ|A|ψ⟩ = ⟨Aϕ|ψ⟩）的算符；任何量子态下其平均值为实数，反之平均值为实数的算符为厄米算符。
- **本征态与本征值**：测量力学量 O 结果完全确定（涨落为零）时，态满足 Oψₙ = Oₙψₙ，Oₙ 即本征值；力学量观测值总是实数，故相应算符为厄米算符。
- **厄米算符本征函数的正交性**：属于不同本征值的本征函数彼此正交。
- **对易**：两个算符同时具有确定观测值的必要条件是彼此对易，[A, B] = 0。
- **角动量算符**：定义 l = r × p；其与位置、动量、角动量自身的对易关系构成角动量代数。
- **表象与表象变换**：力学量完全集 F 的共同本征态 {ψₖ} 构成正交归一完备基矢，此基矢下称 F 表象；同一态在不同表象下的展开系数由变换矩阵 S 联系。
- **投影算符**：Pₖ = |ψₖ⟩⟨ψₖ|，作用于态可挑选出基矢方向的分量；完备基矢满足完备性关系 Σₖ|ψₖ⟩⟨ψₖ| = I。
- **算符的矩阵表示**：算符 L 在 F 表象中的矩阵元 Ljk = ⟨ψⱼ|L|ψₖ⟩；算符本征方程在本征表象中化为矩阵本征方程。
- **时间演化**：由薛定谔方程的形式解给出；本征态演化只带动力学相位因子 e^{−iεₖt/ħ}。直接方法为：先求系统本征态，将初始态在本征态上展开，再加入时间演化相位因子。
- **均匀环 / 均匀链**：均匀环相邻点及首尾相互作用的周期性边界条件；均匀链首尾无相互作用的开放边界条件。单粒子本征值与波矢均呈余弦形式。
- **离散散射**：在一维离散格点上引入散射势，入射平面波在势点反射与透射；透射率与反射率满足 R + T = 1。

## 重要公式

**第 1 章 希尔伯特空间**

- **R³ 点乘（实内积）**： `(x_1,x_2,x_3)·(y_1,y_2,y_3) = x_1y_1 + x_2y_2 + x_3y_3`
- **实内积的角度表达**： `x·y = |x||y|cos θ`
- **复数模方**： `|z|^2 = z z^*,  z = x + iy,  |z| = sqrt{x^2 + y^2}`
- **一对复数的内积**： `⟨z,w⟩ = z^* w = (x_z x_w + y_z y_w) + i(x_z y_w - y_z x_w)`
- **C² 中矢量内积**： `⟨z,w⟩ = z_1^* w_1 + z_2^* w_2,  ⟨w,z⟩ = w_1^* z_1 + w_2^* z_2`
- **内积公理**： `⟨x,y⟩ = ⟨y,x⟩^*;  ⟨x, a y_1 + b y_2⟩ = a⟨x,y_1⟩ + b⟨x,y_2⟩;  ⟨a x_1 + b x_2, y⟩ = a^*⟨x_1,y⟩ + b^*⟨x_2,y⟩;  ⟨x,x⟩ ≥ 0`
- **数乘条件**： `ψ1 = ψ,  (ψa)b = ψ(ab),  ψ(a+b) = ψa + ψb,  (ψ+ϕ)a = ψa + ϕa`
- **内积四条件**： `⟨ψ,ϕ⟩ = ⟨ϕ,ψ⟩^*;  ⟨ψ,ϕ+χ⟩ = ⟨ψ,ϕ⟩ + ⟨ψ,χ⟩;  ⟨ψ,ϕa⟩ = ⟨ψ,ϕ⟩a;  ⟨ψ,ψ⟩ ≥ 0（⟨ψ,ψ⟩=0 ⇒ ψ=0）`
- **模方与模**： `⟨ψ,ψ⟩ = |ψ|^2,  |ψ| = sqrt{⟨ψ,ψ⟩}`
- **Cauchy-Schwartz 不等式**： `|⟨ψ,ϕ⟩| ≤ |ψ|·|ϕ|`（提示：`⟨ψ−Cϕ, ψ−Cϕ⟩ ≥ 0, C = ⟨ϕ,ψ⟩/|ϕ|^2`）
- **三角形不等式**： `|ψ+ϕ| ≤ |ψ| + |ϕ|`（提示：`|ψ+ϕ|^2 ≤ |ψ|^2 + |ϕ|^2 + 2|ψ||ϕ|`）
- **线性无关**： `Σ_{i=1}^n ψ_i a_i = 0 ⇔ a_i = 0 (i=1,2,…,n)`
- **完全集展开**： `ψ = Σ_{i=1} λ_i a_i`
- **正交归一基矢**： `⟨v_i, v_j⟩ = δ_{ij},  i,j = 1,2,…,n`
- **Schmidt 正交化**： `v_1 = λ_1/|λ_1|;  v_2 = v_2'/|v_2'|,  v_2' = λ_2 − v_1⟨v_1, λ_2⟩;  v_{m+1} = v_{m+1}'/|v_{m+1}'|,  v_{m+1}' = λ_{m+1} − Σ_{i=1}^m v_i⟨v_i, λ_{m+1}⟩`
- **四个等价命题**：（1）{vᵢ} 是基；（2）`ψ = Σ_{i=1}^n v_i⟨v_i,ψ⟩`；（3）`⟨ϕ,ψ⟩ = Σ_{i=1}^n ⟨ϕ,v_i⟩⟨v_i,ψ⟩`；（4）`|ψ|^2 = Σ_{i=1}^n |⟨v_i,ψ⟩|^2`
- **狄拉克记号内积性质**： `⟨ϕ|ψ⟩ = ⟨ψ|ϕ⟩^*,  ⟨ψ|(|ϕ⟩a) = ⟨ψ|ϕ⟩a,  (a⟨ψ|)|ϕ⟩ = a⟨ψ|ϕ⟩`
- **左矢与右矢对应（数乘）**： `a^*⟨ψ| ↔ |ψ⟩a ≡ |ψa⟩,  ⟨ψa| = a^*⟨ψ|`
- **基矢展开（左/右矢）**： `⟨ψ| = Σ_i ⟨ψ|v_i⟩⟨v_i|,  |ψ⟩ = Σ_i |v_i⟩⟨v_i|ψ⟩,  ⟨ϕ|ψ⟩ = Σ_i ⟨ϕ|v_i⟩⟨v_i|ψ⟩`
- **基矢正交归一**： `⟨v_i|v_j⟩ = δ_{ij},  |ψ| = sqrt{⟨ψ|ψ⟩}`

**第 2 章 态和薛定谔方程**

- **德布罗意关系**： `ν = E/h,  λ = h/p`
- **氢原子驻波条件与角动量量子化**： `2πr = nλ,  J = rp = nh/(2π) = nħ (n=1,2,3,…)`
- **无限深方势阱驻波条件**： `nλ/2 = a,  λ_n = 2a/n;  p_n = nh/(2a);  E_n = n^2 h^2/(8ma^2) = n^2 π^2 ħ^2/(2ma^2)`
- **归一化条件**： `∫_{-∞}^{+∞} |ψ(x)|^2 dx = 1;  ∫_{-∞}^{+∞} |ψ(x_1,x_2,…)|^2 dx_1 dx_2 … = 1`
- **态的叠加**： `ψ(r,t) = c_1 ψ_1(r,t) + c_2 ψ_2(r,t)`
- **自旋 1/2 叠加态例**： `ψ = (1/sqrt{2})(ψ_1 + ψ_2);  ψ_1 = (1,0)^T, ψ_2 = (0,1)^T`
- **动量本征态（平面波）**： `ψ_{p_0} = exp(i p_0 x/ħ),  |ψ_{p_0}(x)|^2 = 1`
- **位置本征态（δ 函数）**： `ψ_{x_0}(x) = δ(x − x_0)`
- **位置本征态的傅立叶展开**： `φ_{x_0}(p) = (1/sqrt{2π})∫_{-∞}^{+∞} ψ_{x_0}(x) e^{−ipx/ħ} dx = (1/sqrt{2π}) e^{−ipx_0/ħ},  |φ_{x_0}(p)|^2 = 1/(2π)`
- **高斯波包及其变换**： `ψ(x) = e^{−α^2 x^2/2},  Δx ≈ 1/α;  φ(k) = (1/sqrt{2π})∫ ψ(x) e^{−ikx} dx = (1/α) e^{−k^2/(2α^2)},  Δx Δk ≈ 1`
- **不确定关系（坐标-动量）**： `Δx Δp ≈ ħ`
- **Heisenberg 不确定关系**： `ΔA·ΔB ≥ (1/2)|⟨[A,B]⟩|`
- **坐标-动量不确定关系**： `A = x, B = p_x, [x,p_x] = iħ ⇒ Δx Δp ≥ ħ/2`
- **自由粒子关系与平面波**： `E = p^2/(2m);  ω = E/ħ, k = p/ħ;  ψ ∝ e^{i(k·r − ωt)} = e^{i(p·r − Et)/ħ}`
- **薛定谔方程（自由粒子 → 含势场）**： `iħ ∂ψ/∂t = −(ħ^2/2m)∇^2 ψ;  iħ ∂ψ/∂t = Hψ,  H = −(ħ^2/2m)∇^2 + V`
- **概率守恒（连续性方程）**： `∂ρ/∂t + ∇·j = 0;  ρ = ψ^*ψ,  j = −(iħ/2m)(ψ^*∇ψ − ψ∇ψ^*)`
- **不含时薛定谔方程（本征方程）**： `Hψ(r) = Eψ(r),  H = −(ħ^2/2m)∇^2 + V(r)`
- **定态演化**： `ψ(r,0) = ψ_E(r) ⇒ ψ(r,t) = ψ_E(r) e^{−iEt/ħ};  ψ^*ψ = Const.`
- **叠加态演化**： `ψ(r,0) = Σ_E c_E ψ_E(r) ⇒ ψ(r,t) = Σ_E c_E ψ_E(r) e^{−iEt/ħ}`
- **无限深方势阱解**： `V(x) = 0 (0 ≤ x ≤ a), V(x) = ∞ (x < 0, x > a);  ψ(x) = A sin(kx + δ), k = sqrt{2mE}/ħ;  ka = nπ`
- **能级与归一化波函数**： `E_n = π^2 ħ^2 n^2/(2ma^2);  ψ_n(x) = sqrt{2/a} sin(nπx/a), n = 1,2,3,…`
- **算符平均值**： `⟨O⟩ = ∫ ψ^* O ψ d^3x = ⟨ψ|O|ψ⟩`
- **动量算符**： `p̂ = −iħ∇`
- **本征态展开下的平均值**： `⟨O⟩ = Σ_n |⟨ϕ_n|ψ⟩|^2 O_n = Σ_n C_n O_n,  ⟨ϕ_n|ψ⟩ = C_n`
- **线性算符**： `O(c_1ψ_1 + c_2ψ_2) = c_1 Oψ_1 + c_2 Oψ_2`
- **单位算符与算符和积**： `Iψ = ψ;  (A+B)ψ = Aψ + Bψ;  ABψ = A(Bψ)`
- **对易关系代数**： `[A,B] = AB − BA;  [A,B] = −[B,A];  [A,A] = 0;  [A,c] = 0;  [A,B+C] = [A,B]+[A,C];  [A,BC] = B[A,C] + [A,B]C;  [AB,C] = A[B,C] + [A,C]B;  [A,[B,C]] + [B,[C,A]] + [C,[A,B]] = 0`
- **位置-动量对易关系**： `[x, p_x] = iħ;  [r_α, p_β] = iħ δ_{αβ},  α,β = x,y,z`
- **角动量算符（笛卡尔分量）**： `l = r × p;  l_x = y p_z − z p_y = −iħ(y ∂/∂z − z ∂/∂y);  l_y = z p_x − x p_z;  l_z = x p_y − y p_x`
- **角动量与位置对易**： `[l_x,x] = 0, [l_x,y] = iħz, [l_x,z] = −iħy;  [l_y,x] = −iħz, [l_y,y] = 0, [l_y,z] = iħx;  [l_z,x] = iħy, [l_z,y] = −iħx, [l_z,z] = 0`
- **角动量对易关系（Levi-Civita）**： `[l_α, r_β] = ε_{αβγ} iħ r_γ;  [l_α, p_β] = ε_{αβγ} iħ p_γ;  [l_α, l_β] = ε_{αβγ} iħ l_γ`
- **逆算符**： `Aψ = ϕ ⇒ A^{−1}ϕ = ψ;  A A^{−1} = A^{−1} A = I;  [A, A^{−1}] = 0`（投影算符无逆）
- **共轭 / 转置算符**： `p_x^* = iħ ∂/∂x = −p_x;  ∫ dτ ϕ^* A ψ = ∫ dτ ψ A ϕ`（后式为转置）
- **转置共轭（厄米共轭）算符**： `⟨ϕ|A|ψ⟩ = (A^† ϕ|ψ⟩ = ⟨A^†ϕ|ψ⟩;  (A+B)^† = A^† + B^†;  (AB)^† = B^† A^†`（A,B 对易时 (AB)^† = AB）
- **厄米算符**： `A^† = A ⇔ ⟨ϕ|A|ψ⟩ = ⟨Aϕ|ψ⟩`（两厄米算符之积在对易时为厄米）
- **厄米算符推论**： `⟨O^2⟩ = ⟨ψ|O^2|ψ⟩ = ⟨Oψ|Oψ⟩ ≥ 0`
- **涨落（方差）**： `ΔO^2 = ⟨(O − ⟨O⟩)^2⟩ = ∫ ψ^* (O − ⟨O⟩)^2 ψ dτ`
- **本征方程与本征值**： `Oψ_n = O_n ψ_n;  ⟨O⟩ = ⟨ψ_n|O|ψ_n⟩ = O_n`
- **不同本征值本征函数正交**： `(O_m − O_n)⟨ψ_n|ψ_m⟩ = 0, O_m ≠ O_n ⇒ ⟨ψ_n|ψ_m⟩ = 0`
- **态的表象变换**： `a'_{k'} = Σ_k S_{k'k} a_k,  S_{k'k} = ⟨ψ'_{k'}|ψ_k⟩`
- **力学量的表象变换**： `L'_{αβ} = ⟨ψ'_α|L|ψ'_β⟩ = Σ_{kj} S_{αk} L_{kj} S^†_{jβ} = (S L S^†)_{αβ};  L' = S L S^† = S L S^{−1}`
- **投影算符与完备性关系**： `P_k = |ψ_k⟩⟨ψ_k|;  P_k|ψ⟩ = a_k|ψ_k⟩;  Σ_k |ψ_k⟩⟨ψ_k| = I`
- **展开态与交叠**： `|ϕ⟩ = Σ_k a_k|ψ_k⟩, a_k = ⟨ψ_k|ϕ⟩;  ⟨ϕ|φ⟩ = Σ_k a_k^* b_k`
- **算符的矩阵元与矩阵形式**： `L_{jk} = ⟨ψ_j|L|ψ_k⟩;  b_k = Σ_j L_{kj} a_j`
- **本征方程的矩阵形式**： `Σ_k L_{jk} a_k = L' a_j ⇔ Σ_k (L_{jk} − L'δ_{jk}) a_k = 0;  det(L − L'I) = 0`
- **薛定谔方程的矩阵形式**： `iħ d/dt a_j(t) = Σ_k H_{jk} a_k(t),  H_{jk} = ⟨ψ_j|H|ψ_k⟩`
- **平均值（矩阵形式）**： `⟨L⟩ = Σ_{j,k} a_j^* L_{jk} a_k`
- **时间演化（形式解）**： `iħ d/dt |Ψ(t)⟩ = H|Ψ(t)⟩ ⇒ |Ψ(t)⟩ = e^{−iHt/ħ}|Ψ(0)⟩`
- **哈密顿量谱分解与演化**： `H = Σ_k ε_k |k⟩⟨k|, ⟨k|H|k'⟩ = ε_k δ_{kk'};  |Ψ(t)⟩ = Σ_k C_k e^{−iε_k t/ħ}|k⟩,  C_k = ⟨k|Ψ(0)⟩`
- **二能级算例**： `H = (0 1; 1 0),  |±⟩ = (1/sqrt{2})(1,±1)^T;  初始 (1,0)^T ⇒ |Ψ(t)⟩ = (cos(ωt), −i sin(ωt))^T`
- **三对角哈密顿量**： `H = (0 1 0; 1 0 1; 0 1 0) ⇒ 2E − E^3 = 0 ⇒ E_0 = 0, E_± = ±sqrt{2}`
- **均匀环（周期性边界）本征值/本征态**： `E_n = 2cos(2πn/N), n = 1,2,…,N;  ψ_n(j) = (1/sqrt{N}) e^{i (2πn/N) j};  k = 2πn/N`
- **均匀链（开放边界）本征值/本征态**： `E_n = 2cos(nπ/(N+1)), n = 1,2,…,N;  ψ_n(j) = sqrt{2/(N+1)} sin(nπ j/(N+1));  k = nπ/(N+1)`
- **离散散射（单势）**： `ψ_{j−1} + ψ_{j+1} = Eψ_j (j≠0),  ψ_{−1} + Vψ_0 + ψ_1 = Eψ_0;  E = e^{−ik} + e^{ik}`
- **单势透射/反射系数**： `t = 2i sin k/(2i sin k + V),  r = t − 1 = −V/(2i sin k + V)`
- **单势透射率/反射率**： `T = |t|^2 = 4sin^2 k/(4sin^2 k + V^2),  R = |r|^2 = V^2/(4sin^2 k + V^2),  R + T = 1`
- **离散散射（双势，耦合 g）**： `ψ_{−1} + gψ_1 = Eψ_0,  gψ_0 + ψ_2 = Eψ_1;  E = e^{−ik} + e^{ik}`
