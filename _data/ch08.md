## 核心概念
- **散射实验**：一束入射粒子轰击靶物质，碰撞总数正比于入射粒子总数与单位面积内的靶粒子数；探测器位于距靶远大于靶尺寸处，测量的是大 $r$ 处波函数的渐近行为。
- **微分散射截面 $d\sigma/d\Omega$**：单位时间散射进立体角元 $d\Omega$（方向 $(\theta,\phi)$）的粒子数除以入射流密度，具有面积量纲。
- **入射流密度 $J_{\text{inc}}$**：单位面积单位时间通过的入射粒子数。
- **总散射截面 $\sigma$**：$d\sigma/d\Omega$ 对全立体角的积分。
- **散射振幅 $f(\theta,\phi)$**：刻画散射波方向分布的复函数；弹性散射下 $d\sigma/d\Omega=|f|^2$。
- **实验室系（Lab）与质心系（CM）**：Lab 系靶初始静止，CM 系质心静止；散射角与截面在两系间需要换算。
- **玻恩近似**：当势 $V(r)$ 足够弱、散射波相对入射平面波只发生微小畸变时，用入射平面波近似积分方程中的未知波函数得到的微扰解（迭代级数即玻恩级数）。
- **动量转移 $\hbar q$**：$\vec q=\vec k_0-\vec k$，$\vec k_0,\vec k$ 分别为入射、散射波矢；弹性散射时 $q=2k\sin(\theta/2)$。
- **卢瑟福公式**：库仑势下玻恩近似给出的微分截面，正比于 $1/\sin^4(\theta/2)$。
- **分波法**：把散射波按角动量本征态（分波，$l$ 为轨道角动量）展开，各分波独立受势畸变；每项是 $\hat L^2$ 与 $\hat L_z$ 的共同本征函数。
- **相移 $\delta_l$**：第 $l$ 个分波径向函数在无穷远处相对自由球面波的相位差，度量势造成的畸变；无势时 $\delta_l=0$。
- **散射长度**：低能 s 波极限下的量 $R=-\delta_0/k$（$k\to 0$），刻画低能散射强度。
- **Ramsauer–Townsend 效应**：当 $\delta_0=\pi$（$2\delta_0=2\pi$）时该分波截面为零（$\sin^2\delta_0=0$），出现近乎完美的透射，电子被稀有气体散射时曾被观测到。
- **光学定理**：总截面与前向散射振幅虚部的关系 $\operatorname{Im} f(0)=\frac{k}{4\pi}\sigma_{\text{tot}}$，源于粒子（概率）守恒，对弹性与非弹性散射均成立。
- **非弹性散射的分波分析**：用 $\eta_l(k)$（$0\le\eta_l\le1$）描述吸收（通量损失）；$\eta_l=1$ 无吸收，$\eta_l=0$ 完全吸收。
- **全同粒子的散射**：两全同粒子散射时波函数必须对称/反对称，散射振幅需叠加 $f(\theta)\pm f(\pi-\theta)$，出现干涉项；自旋 $1/2$ 粒子分自旋单态（空间对称）与三重态（空间反对称）。

## 重要公式
- **微分散射截面定义**（11.1）：`dσ/dΩ = (1/J_inc) dN(θ,φ)/dΩ`，其中 $dN$ 为单位时间散射进立体角 $d\Omega$ 的粒子数。
- **总截面与微分截面关系**（11.2）：`σ = ∫ (dσ/dΩ) dΩ = ∫₀^{2π} ∫₀^{π} (dσ/dΩ) sinθ dθ dφ`
- **渐近散射波函数**（11.34）：`ψ(r) → A[ e^{i k₀·r} + f(θ,φ) e^{ikr}/r ]`（A 为归一化因子，可取 1）
- **散射振幅定义**（11.33）：`ψ_sc(r) = A f(θ,φ) e^{ikr}/r`
- **入射与散射流密度**（11.37）：`J_inc = (ħ k₀/E)|A|²`，`J_sc = (ħ k/(E r²))|A|² |f(θ,φ)|²`
- **弹性散射振幅—截面关系**（11.41）：`dσ/dΩ = |f(θ,φ)|²`
- **Lab/CM 散射角关系**（11.14）（11.15）：`tanθ₁ = sinθ / (cosθ + m₁/m₂)`，`cosθ₁ = (m₁/m₂ + cosθ)/√(1 + (m₁/m₂)² + 2(m₁/m₂)cosθ)`
- **Lab/CM 截面变换**（11.19）（11.20）：`dσ(θ₁,φ₁) = dσ(θ,φ)`（散射粒子数不变），因而 `(dσ/dΩ)|_Lab = (dσ/dΩ)|_CM · (dcosθ/dcosθ₁)`
- **玻恩近似散射振幅**（11.65）：`f(θ) = -(2m/(4π ħ²)) ∫ e^{i q·r'} V(r') d³r'`，`q = k₀ - k`
- **玻恩近似微分截面**（11.66）：`dσ/dΩ = (2m/(4π ħ²))² | ∫ e^{i q·r'} V(r') d³r' |²`
- **球对称势的玻恩振幅**（11.68）（11.69）：`f(θ) = -(2m/(ħ² q)) ∫₀^∞ r V(r) sin(qr) dr`，`q = 2k sin(θ/2)`
- **玻恩近似适用条件**（11.71）：`| (2m/(4π ħ²)) ∫ (e^{ikr'}/r') V(r') e^{i k₀·r'} d³r' | ≪ 1`（散射项远小于入射平面波）
- **库仑（卢瑟福）公式**（11.77）：`dσ/dΩ = Z₁²Z₂² e⁴ / (16 E² sin⁴(θ/2))`，`E = ħ²k²/2m`
- **平面波分波展开**（11.81）：`e^{ikr cosθ} = Σ_l iˡ (2l+1) j_l(kr) P_l(cosθ)`
- **径向方程**（11.84）：`[d²/dr² - l(l+1)/r² + k² - (2m/ħ²) V(r)] (r R_kl(r)) = 0`
- **径向函数渐近形式**（11.93）：`R_kl(r) → C_l sin(kr - lπ/2 + δ_l)/kr`
- **分波展开的散射振幅**（11.99）：`f(θ) = (1/k) Σ_l (2l+1) e^{iδ_l} sinδ_l P_l(cosθ) = (1/(2ik)) Σ_l (2l+1)(e^{2iδ_l}-1) P_l(cosθ)`
- **分波振幅**：`f_l(k) = (1/k) e^{iδ_l} sinδ_l`
- **微分截面分波展开**（11.100）：`dσ/dΩ = |f(θ)|² = (1/k²) |Σ_l (2l+1) e^{iδ_l} sinδ_l P_l(cosθ)|²`
- **总截面分波展开**（11.102）：`σ = Σ_l σ_l = (4π/k²) Σ_l (2l+1) sin²δ_l`（利用正交关系 `∫₀^π P_l P_{l'} sinθ dθ = 2δ_{ll'}/(2l+1)`）
- **s 波（l=0）振幅与截面**（11.103）（11.104）：`f₀ = (1/k) e^{iδ₀} sinδ₀`，`dσ/dΩ = (1/k²) sin²δ₀`，`σ₀ = (4π/k²) sin²δ₀`
- **光学定理**（11.106）：`Im f(0) = (k/4π) σ_tot`
- **非弹性散射的 S 矩阵**（11.108）–（11.110）：`f_l(k) = (1/(2ik))(S_l(k)-1)`，`S_l(k) = η_l(k) e^{2iδ_l}`，`0 ≤ η_l(k) ≤ 1`
- **弹性散射总截面（含吸收）**（11.113）：`σ_el = (π/k²) Σ_l (2l+1) [1 + η_l² - 2η_l cos 2δ_l]`
- **非弹性散射总截面**（11.114）：`σ_inel = (π/k²) Σ_l (2l+1)(1 - η_l²)`
- **总截面（含吸收）**（11.115）：`σ_tot = σ_el + σ_inel = (2π/k²) Σ_l (2l+1)(1 - η_l cos 2δ_l)`
- **非弹性情形的光学定理**（11.116）：`Im f(0) = (k/4π) σ_tot`（对非弹性散射同样成立）
- **全同玻色子散射**（11.121）（11.122）：`f_boson(θ) = f(θ) + f(π-θ)`，`dσ/dΩ|_boson = |f(θ) + f(π-θ)|²`；当 θ=π/2 时 `(dσ/dΩ)_boson = 4|f(π/2)|²`（为经典值 2 倍）
- **全同自旋 1/2 费米子散射**（11.123）（11.124）：自旋单态 `dσ/dΩ|_S = |f(θ) + f(π-θ)|²`；自旋三重态 `dσ/dΩ|_A = |f(θ) - f(π-θ)|²`
- **硬球散射（s 波）**：`V(r)=∞ (r≤a), V(r)=0 (r>a)`；`u(r)=0 (r<a)`，`u(r)=A sin(kr+δ₀) (r>a)`，`tanδ₀ = -tan(ka)`，最低取值 `δ₀ = -ka`；低能极限 `σ₀ = (4π/k²) sin²δ₀ ≈ 4πa²`（为经典值 πa² 的 4 倍）
- **吸引方势阱（s 波）**：`V(r)=-V₀ (r<a), V(r)=0 (r>a)`；`u₁=A sin(k₁r)`，`u₂=B sin(k₂r+δ₀)`，`k₁=√(2m(E+V₀))/ħ`，`k₂=√(2mE)/ħ`；连续条件给出 `tanδ₀ = (k₂ tan(k₁a) - k₁ tan(k₂a)) / (k₁ + k₂ tan(k₁a) tan(k₂a))`（11.170），代入 `σ₀=(4π/k²) sin²δ₀`（11.172）

## 常见考法（推断）
- 由微分散射截面定义 $d\sigma/d\Omega=(1/J_{\text{inc}})dN/d\Omega$ 推得弹性散射的 $d\sigma/d\Omega=|f(\theta)|^2$，并计算总截面（此小节为推断，可能为空）。
- 用一阶玻恩近似计算给定势（库仑势、汤川势、球对称势）的散射振幅与微分截面，导出卢瑟福公式并讨论其 $E$、$\theta$ 依赖。
- 判断一阶玻恩近似何时成立（势弱、能量高、散射项远小于入射波）。
- 用分波法求相移 $\delta_l$，计算低能 s 波极限下硬球或方势阱的散射截面（含散射长度 $-\delta_0/k$、Ramsauer–Townsend 效应）。
- 应用光学定理 $\operatorname{Im}f(0)=\frac{k}{4\pi}\sigma_{\text{tot}}$ 由前向振幅求总截面（含非弹性推广）。
- 处理全同粒子散射：玻色子与费米子（自旋单态/三重态）截面中的干涉项，及 $\theta=\pi/2$ 或高能极限下与经典值的倍数关系。
