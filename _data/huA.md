## 核心概念
- **量子力学的地位与应用**：量子力学是物理学的基础理论之一，在化学、材料学、生物学、宇宙学等学科及近代技术中都有广泛应用。
- **经典物理学的成功**：19 世纪末物理学理论已相当完善；牛顿方程成功描述从天体到地面各种尺度力学客体的运动（并用于分子运动论），汤姆森 1897 年发现电子表明其行为类似牛顿粒子；杨 1803 年衍射实验揭示光的波动性，麦克斯韦 1864 年建立光与电磁现象的联系。
- **经典物理学的困难**：进入 20 世纪后经典理论在解释新实验上遇到严重困难，主要有三个：（1）黑体辐射；（2）光电效应；（3）氢原子光谱。
- **黑体**：能吸收射到其上的全部辐射的物体，称为绝对黑体（简称黑体），由 Kirchhoff 引入。
- **辐射热平衡状态**：处于某一温度 $T$ 的物体，单位面积所发射的辐射能量与其吸收的辐射能量相等时，辐射达到热平衡状态。
- **黑体辐射的实验规律**：热平衡时，空腔辐射的能量密度随波长的分布曲线，其形状和位置只与黑体的绝对温度 $T$ 有关，而与黑体的形状和材料无关。
- **Wien 公式（1896）**：基于热力学及一些特殊假设得到，在短波部分与实验相符，长波部分明显不一致。
- **Rayleigh–Jeans 公式**：在长波部分与实验结果较符合，短波部分完全不符（经典理论在短波端的困难）。
- **光电效应**：光照射到金属上，有电子从金属上逸出的现象，这种电子称为光电子。两个突出特点：（1）存在临界频率 $\nu_0$，只有光频率大于 $\nu_0$ 才有光电子发射，频率小于 $\nu_0$ 时无论光强多大、照射多久都无电子产生；（2）电子能量只与光的频率有关、与光强无关，光强只决定电子数目的多少。这是经典（光的电磁理论）无法解释的。
- **临界频率 $\nu_0$**：光生电子所需的最小光频率，$\nu_0=A/h$。
- **Balmer 公式**：1885 年瑞士 Balmer 发现紫外附近的线系，得出氢原子谱线的经验公式。
- **氢原子光谱线系**：由分立谱线组成，可统一写成含 $m,n$ 的公式；谱系包括 Lyman（$m=1$，远紫外）、Balmer（$m=2$，可见）、Paschen（$m=3$，红外）、Brackett（$m=4$，远红外）、Pfund（$m=5$，超远红外）。
- **经典理论对原子光谱的困难**：按经典电动力学，电子绕核作加速运动会不断辐射能量而最终"掉入"核中，原子应"崩溃"，但原子实际稳定存在；经典物理不能解释谱线频率的简单规律与原子线状光谱的产生机制。
- **Planck 黑体辐射定律**：1900 年 12 月 14 日 Planck 假定（1）原子性能与谐振子一样以给定频率 $\nu$ 振荡；（2）黑体只能以 $E=h\nu$ 为能量单位不连续地发射和吸收辐射，而非经典理论所要求的连续方式。
- **光量子（光子）概念**：Einstein 1905 年提出，第一个肯定光具有微粒性；电磁辐射在发射和吸收时以能量 $h\nu$ 的微粒形式出现，并以光速 $c$ 在空间传播，这种粒子叫光量子或光子。
- **光子静质量为零**：由相对论能量关系，光子速度 $V=c$，欲使能量式有意义必须令 $m_0=0$，即光子静质量为零。
- **光子能量—动量关系**：由相对论能量动量关系得 $E=pC$，即 $p=E/C$，把光子的波动性和粒子性联系起来。
- **Compton 效应**：X 射线被轻元素（如白蜡、石墨）中的电子散射后出现的效应。特点：（1）散射光中除原波长 $\lambda$ 外增加了新波长 $\lambda'$ 且 $\lambda'>\lambda$；（2）波长增量 $\Delta\lambda=\lambda'-\lambda$ 随散射角增大而增大。经典电动力学无法解释新波长的出现，而用光子与电子的碰撞过程则容易理解。
- **Compton 效应的定性解释**：具有能量 $E=h\nu$ 的光子与电子碰撞后把部分能量传给电子，光子能量变为 $E'=h\nu'$，有 $E'<E$，从而 $\nu'<\nu$，散射后频率减小、波长变长。
- **电子 Compton 波长 $\lambda_0$**：$\lambda_0=\dfrac{2\pi\hbar}{m_0 c}\approx 2.4\times10^{-10}\ \mathrm{cm}$；$\Delta\lambda$ 恒大于或等于零，故散射波波长总比入射波长长，且随散射角增大而增大。
- **Bohr 假定（两层概念）**：（1）原子具有能量不连续的**定态**，稳定态只可能是某些具有分立能量 $E_1,E_2,\dots,E_n$ 的状态；其量子化条件为电子的角动量 $L$ 只能取 $\hbar$ 的整数倍，$L=n\hbar$。（2）**量子跃迁**概念：原子处于定态时不辐射，电子可从能级 $E_n$ 跃迁到 $E_m$，同时发射（吸收）一个光子。
- **氢原子线光谱的解释**：由 Bohr 两个概念可圆满解释氢原子线光谱，并得到与实验完全一致的 Rydberg 常数。
- **第一 Bohr 轨道半径 $r_0$**：$r_0=\dfrac{\hbar^2}{\mu e^2}$。
- **索末菲量子化条件的推广**：将角动量选为广义动量作积分，得到推广后的量子化条件，可用于多自由度情况；不但能解释氢原子光谱，对只有一个电子的原子（Li、Na、K 等）光谱也能很好解释。
- **Bohr 量子论的局限性**：① 不能解释比氢稍复杂的氦原子光谱；② 不能给出谱线强度（相对强度）；③ 只能处理周期运动，不能处理非束缚态（如散射）问题；④ 能量量子化概念与经典力学不相容，带有人为性，物理本质不清楚。

## 重要公式
- **Wien 公式**： `\rho_\nu\,d\nu = C_1 \nu^{3}\exp(-C_2 \nu / T)\,d\nu`
- **Rayleigh–Jeans 公式**： `\rho_\nu\,d\nu = \frac{8\pi}{c^{3}} kT\,\nu^{2}\,d\nu`
- **Planck 辐射定律**： `\rho_\nu\,d\nu = \frac{8\pi h \nu^{3}}{c^{3}}\frac{1}{\exp(h\nu/kT)-1}\,d\nu`
- **Planck 定律的短波极限 → Wien 公式**： `\rho_\nu\,d\nu \approx \frac{8\pi h \nu^{3}}{c^{3}}\exp(-h\nu/kT)\,d\nu`
- **Planck 定律的长波极限 → Rayleigh–Jeans 公式**： `\rho_\nu\,d\nu \approx \frac{8\pi \nu^{2}}{c^{3}} kT\,d\nu`
- **光电效应方程**： `\frac{1}{2}\mu V^{2} = h\nu - A`
- **临界频率**： `\nu_0 = A / h`
- **光子能量**： `E = h\nu = \hbar\omega`
- **光子动量**： `\vec{p} = \frac{E}{C}\vec{n} = \frac{h\nu}{C}\vec{n} = \frac{h}{\lambda}\vec{n} = \hbar\vec{k}`
- **（约化）普朗克常数与波数**： `\hbar = \frac{h}{2\pi},\quad k = \frac{2\pi}{\lambda}`
- **相对论能量动量关系**： `E^{2} = (m_0 c^{2})^{2} + (pc)^{2}`
- **光子能动量关系**： `E = pC \quad\text{或}\quad p = E/C`
- **相对论能量公式**： `E = \frac{m_0 C^{2}}{\sqrt{1 - V^{2}/C^{2}}}`
- **Compton 散射公式（波长增量）**： `\lambda' - \lambda = \frac{2\pi\hbar}{m_0 c}(1-\cos\theta) = \frac{4\pi\hbar}{m_0 c}\sin^{2}\frac{\theta}{2}`
- **Compton 散射（用电子 Compton 波长表示）**： `\Delta\lambda = 2\lambda_0 \sin^{2}\frac{\theta}{2},\quad \lambda_0 = \frac{2\pi\hbar}{m_0 c}`
- **Bohr 量子化条件**： `L = n\hbar,\quad n = 1,2,3,\dots`
- **量子跃迁频率**： `\nu = \frac{E_n - E_m}{h}`
- **氢原子电子轨道半径**： `r = \frac{n^{2}\hbar^{2}}{\mu e^{2}}`
- **第一 Bohr 轨道半径**： `r_0 = \frac{\hbar^{2}}{\mu e^{2}}`
- **氢原子能量（能级）**： `E_n = -\frac{\mu e^{4}}{2 n^{2}\hbar^{2}},\quad n = 1,2,3,\dots`
- **氢原子线光谱（由 Bohr 理论导出）**： `\nu = \frac{E_n - E_m}{h} = \frac{\mu e^{4}}{4\pi\hbar^{3}}\left(\frac{1}{m^{2}} - \frac{1}{n^{2}}\right)`
- **Rydberg 常数（理论值）**： `R_H = \frac{\mu e^{4}}{4\pi\hbar^{3} c}`
- **Balmer 公式**： `\nu = R_H c\left(\frac{1}{2^{2}} - \frac{1}{n^{2}}\right),\quad n = 3,4,5,\dots`
- **氢原子光谱一般公式**： `\nu = R_H c\left(\frac{1}{m^{2}} - \frac{1}{n^{2}}\right),\quad n > m`
- **氢的 Rydberg 常数实验值**： `R_H = 1.097373 \times 10^{7}\ \mathrm{m^{-1}}`
- **Bohr 量子化条件的积分形式**： `\oint L\,d\theta = n\hbar\oint d\theta = 2\pi n\hbar = nh`
- **索末菲推广的量子化条件**： `\oint p_i\,dq_i = n_i h`
