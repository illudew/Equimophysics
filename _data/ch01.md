## 核心概念
- **经典物理的四条"确定性"信念**：1900 年前人们相信宇宙是决定论的、光是波而物质是粒子、物理量（能量、动量等）连续、存在与观察者无关的客观实在。
- **量子力学的四条修正**：宇宙不再决定论（只能给出概率）；光与物质都兼具波粒二象性；某些物理量只能取分立值（量子化）；观察者总会影响实验，无法把二者分开。
- **黑体（Blackbody）**：吸收所有入射辐射、加热时又发出所有辐射的理想物体；最简单的实现是空心腔壁上的小孔。
- **基尔霍夫定律（Kirchhoff's law）**：给定温度下，腔体内平衡辐射的组成只与温度有关，与物质性质无关。
- **维恩位移定律（Wien's displacement law）**：黑体谱峰值波长随温度升高向短波移动。
- **斯特藩–玻尔兹曼定律（Stefan–Boltzmann law）**：单位面积总辐射功率正比于绝对温度的四次方。
- **瑞利–金斯公式与紫外灾难（Rayleigh–Jeans formula / ultraviolet catastrophe）**：经典理论给出的黑体谱在短波（高頻）端发散，是经典物理无法解释的困难之一。
- **普朗克公式与能量子（Planck's law / energy quantum）**：普朗克假设谐振子能量只能取 $nhf$ 的分立值并只能以 $\Delta E=hf$ 跳跃变化，从而插值得到与实验一致的黑体谱。
- **光电效应（Photoelectric effect）**：光照射材料使电子逸出；电子最大动能只依赖光频率与材料功函数，与光强无关，且存在阈值频率。
- **功函数与遏止电压（work function $\phi$ / stopping potential $V_0$）**：$\phi$ 是电子逸出所需最小束缚能，$eV_0$ 等于电子最大动能。
- **光量子（光子，photon）**：爱因斯坦提出辐射场本身量子化，每个光量子能量为 $h\nu$。
- **康普顿效应（Compton effect）**：X 射线被（静止自由）电子散射后波长变长，是光子粒子性的又一定量证据。
- **康普顿波长（Compton wavelength）**：$h/m_ec\approx 0.0243\ \text{Å}$。
- **德布罗意波 / 物质波（de Broglie wave / matter wave）**：粒子本身也具有波动性，波长由普朗克常数除以粒子动量给出。
- **玻尔量子化条件（Bohr's quantization condition）**：把电子轨道看作驻波，$2\pi r=n\lambda$，由此得角动量量子化 $L=n\hbar$。
- **戴维孙–革末实验（Davisson–Germer experiment, 1925）**：电子被镍晶体散射出现衍射峰，直接验证了德布罗意波长假设。
- **布拉格定律（Bragg's law）**：晶体点阵面对波的相干衍射条件，可用来验算电子波长。
- **波包（wave packet）**：大量不同（波长/频率）平面波叠加形成在空间局域的脉冲，用来描述具有粒子性的运动。
- **相速度与群速度（phase / group velocity）**：相速度 $v_{ph}=\omega/k$ 描述单色波的相位传播，群速度 $v_g=d\omega/dk$ 描述波包（即粒子）整体的传播。
- **高斯波包与最小不确定度波包（Gaussian wave packet）**：使不确定度关系取等号，是"最小不确定度"波包。
- **不确定度原理（Uncertainty principle）**：无法同时精确测知同一粒子的位置与动量，$\Delta p_x\Delta x\ge\hbar/2$。
- **电子双缝实验（Electron double-slit experiment）**：单个电子逐个通过双缝仍形成干涉图样，说明经典"粒子"与"波"的描述都不完全。
- **波函数与概率幅（wave function / probability amplitude）**：$\Psi(r,t)$ 描述量子态，其模方为概率密度；概率幅为复函数。
- **概率密度（probability density）**：$P=|\psi|^2$ 表示在位置 $r$、时刻 $t$ 发现粒子的概率密度。
- **薛定谔方程（Schrödinger equation）**：量子力学的基本动力学方程，分含时与定态两种形式。
- **哈密顿–雅可比理论（Hamilton–Jacobi theory）**：经典力学的作用量 $S$ 与波函数相位相联系，由 $S$ 出发可导出薛定谔方程（程函近似）。
- **概率流密度与连续性方程（probability current / continuity equation）**：局域概率守恒，$\partial P/\partial t+\nabla\cdot S=0$。
- **期望值（expectation value）**：可观测量（算符）在给定态下的平均测量值。

## 重要公式
- **维恩位移定律**： `\lambda_{\max}T = 2.898\times10^{-3}\ \text{m}\cdot\text{K}`
- **斯特藩–玻尔兹曼定律**： `e_{\text{total}} = \sigma T^{4},\quad \sigma = 5.67\times10^{-8}\ \text{W}\,\text{m}^{-2}\text{K}^{-4}`
- **光谱强度与能量密度关系**： `J(f,T) \simeq u(f,T)\,c/4`
- **维恩指数定律**： `u(f,T) = A f^{3}e^{-\beta f/T}`
- **瑞利–金斯公式（按波长）**： `u(\lambda,T)\,d\lambda = \frac{8\pi}{\lambda^{4}}k_BT\,d\lambda`
- **普朗克黑体辐射公式**： `u(f,T) = \frac{8\pi h f^{3}}{c^{3}}\frac{1}{e^{hf/k_BT}-1}`
- **谐振子能量量子化**： `E_{\text{resonator}} = nhf,\quad \Delta E = hf`
- **光子能量**： `E = h\nu`
- **光电效应方程**： `h\nu = \phi + \tfrac{1}{2}mv_{\max}^{2},\quad eV_0 = \tfrac{1}{2}mv_{\max}^{2} = h(\nu-\nu_0)`
- **康普顿散射波长移动**： `\lambda' - \lambda = \frac{h}{m_ec}(1-\cos\theta)`
- **康普顿波长**： `\frac{h}{m_ec} = 0.0243\ \text{Å} = 0.00243\ \text{nm}`
- **德布罗意关系**： `\lambda = \frac{h}{p}`
- **玻尔量子化条件（驻波）**： `n\lambda = 2\pi r \Rightarrow L = rp = \frac{nh}{2\pi} = n\hbar`
- **布拉格定律**： `n\lambda = 2d\sin\theta`
- **行波与波方程**： `\Psi(x,t) = A\sin\!\big[kx-\omega t+\phi\big],\quad \frac{\partial^{2}\Psi}{\partial x^{2}} = \frac{1}{v^{2}}\frac{\partial^{2}\Psi}{\partial t^{2}}`
- **波包（平面波叠加）**： `\Psi(x,t) = \frac{1}{\sqrt{2\pi}}\int \phi(k)\,e^{i(kx-\omega t)}\,dk`
- **相速度与群速度**： `v_{ph} = \frac{\omega}{k},\qquad v_g = \frac{d\omega}{dk}`
- **高斯波包不确定度关系**： `\Delta x\,\Delta k = \tfrac{1}{2},\qquad \Delta x\,\Delta p = \frac{\hbar}{2}`
- **海森堡不确定度关系**： `\Delta p_x\,\Delta x \ge \frac{\hbar}{2}`
- **由不确定度估计的最小动能**： `E_{\min} \sim \frac{(\Delta p)^{2}}{2m} \sim \frac{\hbar^{2}}{2m\ell^{2}}`
- **自由粒子波函数（相位形式）**： `\psi(x,t) = Ae^{\frac{i}{\hbar}(px-Et)}`
- **动量与能量算符**： `p = -i\hbar\frac{\partial}{\partial x},\qquad E = i\hbar\frac{\partial}{\partial t}`
- **自由粒子薛定谔方程**： `-\frac{\hbar^{2}}{2m}\frac{\partial^{2}\psi}{\partial x^{2}} = i\hbar\frac{\partial\psi}{\partial t}`
- **含势薛定谔方程**： `\Big[-\frac{\hbar^{2}}{2m}\nabla^{2} + V(r)\Big]\psi(r,t) = i\hbar\frac{\partial\psi(r,t)}{\partial t}`
- **哈密顿–雅可比方程与作用量波函数**： `\frac{\partial S}{\partial t} + H(q,p,t) = 0,\qquad \psi = e^{\frac{i}{\hbar}S(r,t)}`
- **连续性方程**： `\frac{\partial P}{\partial t} + \nabla\cdot S = 0,\qquad P = |\psi|^{2}`
- **概率流密度**： `S = \frac{i\hbar}{2m}\big(\psi\nabla\psi^{*} - \psi^{*}\nabla\psi\big)`
- **期望值**： `\langle A\rangle = \int \psi^{*}(r)\,\hat{A}\,\psi(r)\,d^{3}x`

## 常见考法（推断）
- 由光电效应的两道光照（遏止电压与波长关系），求逸出功与截止频率（结合 $eV_0=h\nu-\phi$、$\nu=c/\lambda$）。
- 康普顿散射：给定散射角与波长改变量，求入射波长、散射光子动量及反冲电子能量。
- 黑体辐射相关：用维恩位移定律求峰值波长、用斯特藩–玻尔兹曼定律求辐射功率。
- 德布罗意波长计算（电子/宏观物体），及戴维孙–革末实验中由衍射角反推波长。
- 由波包/不确定度关系估算粒子最小动能或检验 $\Delta x\Delta p\ge\hbar/2$。
- 写出薛定谔方程（含时/定态）并利用概率流守恒/连续性方程分析概率守恒。
