## 核心概念
- **静电场**：电荷静止、所有物理量不随时间变化；此时电场与磁场互不耦合，麦克斯韦方程组的电场部分为 ∇×E=0 与 ∇·D=ρ。
- **静电场的无旋性**：∇×E=0 是其重要特性，导致静电场对电荷做功与路径无关（保守力场），因此可用标量势描述。
- **电势（标势）**：由无旋性引入，E=−∇φ；把单位正电荷从 P₁ 移到 P₂ 电场作的功定义为两点电势差，若作正功则电势下降。
- **零势点的选取**：只有电势差有物理意义；电荷分布于有限区域时常取无穷远为零势点 φ(∞)=0，匀强电场、无限长直导线等电荷不分布于有限区域的体系则只能在有限处选参考点，且一个具体问题只能选一个零势点。
- **给定电荷分布激发的电势**：由点电荷势叠加（叠加原理）得到；连续分布时 φ(x)=∫ρ(x′)/(4πε₀r)dV′，r 为源点到场点距离。
- **泊松方程**：在线性均匀介质中由 ∇·D=ρ 与 D=εE=−ε∇φ 得 ∇²φ=−ρ/ε，是静电势满足的基本微分方程；无自由电荷区化为拉普拉斯方程 ∇²φ=0。
- **静电势的边值关系**：两介质界面上 φ₁=φ₂ 且 ε₁∂φ₁/∂n−ε₂∂φ₂/∂n=σ（n 由 1 指向 2），分别与电场切向连续、D 法向跃变两式对应。
- **导体表面的边值关系**：导体内部不带净电荷、内部电场为零、表面电场沿法线（表面为等势面）；设表面电荷面密度 σ、外部介质电容率 ε，则 φ=常量、ε∂φ/∂n=−σ。
- **静电场的能量**：能量分布于电场中，但可用电荷与电势表示；在线性介质中 W=½∫E·D dV，可化为 W=½∫ρφ dV（积分区为 ρ≠0 的区域）。½ρφ 不是能量密度。
- **导体表面所受静电力**〔蔡〕：面密度 F=σ²/(2ε) ê，方向为负压力（把导体表面向外拉）。
- **二维电荷体系的标度关系**〔蔡〕：二维体系电势、电场随距离的关系比三维情形分别低一阶（如无限长导线 φ∝−ln R、E∝1/R）。
- **唯一性定理（无导体）**：若区域 V 内给定自由电荷分布 ρ，在边界 S 上给定电势 φ|_S 或电势法向导数 ∂φ/∂n|_S，则 V 内电场唯一确定。
- **有导体时的唯一性定理**：确定电场有两类条件——(1) 给定每个导体上的电势 φᵢ；(2) 给定每个导体上的总电荷 Qᵢ（连同导体外电荷分布与边界 S 上的 φ 或 ∂φ/∂n），两种情况都保证解唯一。
- **唯一性定理的证明**：用反证法，设两组解之差 φ=φ′−φ″，则 ∇²φ=0，界面与边界上 φ 或 ∂φ/∂n 为零；由 ∮εφ∇φ·dS=∫ε(∇φ)²dV 得 ∫ε(∇φ)²dV=0，故 ∇φ=0，φ 为常量，解唯一。
- **唯一性定理的意义**〔蔡〕：体现了电荷与电场之间的相互制约关系，也是镜像法、格林函数法等"凑解"方法正确的理论依据。
- **拉普拉斯方程**：当边界选在导体表面、区域内部无自由电荷（ρ=0）时，电势满足 ∇²φ=0；产生电场的电荷全部分布于边界上，其作用通过边界条件进入。
- **分离变量法**：先把场量分解为各单一坐标函数的乘积求出通解，再由边界条件定出常数；不同坐标系的通解不同。
- **本征函数展开法**〔蔡〕：选取满足正交性 ∫U*U′dξ=∝δ 与完备性 ΣU*U′=δ(ξ−ξ′) 的函数系 {U}，将待求函数展开 f(ξ)=ΣaᵢUᵢ(ξ)，再由边界条件确定系数 aᵢ（如 Fourier 积分）。
- **Legendre 函数**〔蔡〕：球坐标轴对称问题的本征函数，P_l(x)=(1/2^l l!)d^l/dx^l(x²−1)^l，x=cosθ；偶数次只有偶次幂项、奇数次只有奇次幂项。
- **镜像法**：区域内有自由电荷（须解泊松方程）而边界为导体或介质界面时，在所求区域之外用假想电荷代替边界感应电荷；若假想电荷与原有电荷的电场满足原边界条件，叠加电势即为唯一正确解（由唯一性定理保证）。
- **格林函数**：位于 x′ 点的单位点电荷所激发的电势，满足 ∇²G(x,x′)=−δ(x−x′)/ε₀；{x 为场点，x′ 为源点}。满足第一类边界条件 φ|_S=0 的称第一类边值问题的格林函数，满足 ∂φ/∂n|_S=−1/(ε₀S) 的称第二类边值问题的格林函数。
- **δ 函数与点电荷密度**：δ(x) 在选择特性 ∫f(x)δ(x)dV=f(0) 下定义；位于 x′ 的点电荷 Q 的密度写作 ρ(x)=Qδ(x−x′)。
- **格林公式**：∫_V[ψ∇²φ−φ∇²ψ]dV=∮_S(ψ∂φ/∂n−φ∂ψ/∂n)dS，对任意两个标量函数适用，是把格林函数与一般边值问题联系起来的桥梁。
- **第一类边值问题**：给定 V 内 ρ 与边界 S 上各点电势 φ|_S。
- **第二类边值问题**：给定 V 内 ρ 与边界上电场法向分量 ∂φ/∂n|_S。
- **电势的多极展开**：电荷分布在小区域（|x′|≪|x|）时，把 1/r=1/|x−x′| 对小量 x′ 作泰勒展开，得到按距离不同幂次排列的多极展开式；每一项有不同的距离依赖与物理意义。
- **电偶极矩**：p=∫ρ(x′)x′dV′；仅对原点不对称的电荷分布才有电偶极矩，对称分布 p=0。正、负电荷体系是最简单的不对称体系。
- **电四极矩**：Dᵢⱼ=∫3xᵢ′xⱼ′ρ(x′)dV′（原始定义），是对称张量；约化定义 Dᵢⱼ=∫(3xᵢ′xⱼ′−r′²δᵢⱼ)ρ(x′)dV′ 为无迹对称张量，只有 5 个独立分量。
- **电四极矩的物理意义**〔蔡〕：反映电荷分布对球对称的偏离；球对称电荷体系无电四极矩，电荷分布偏离球对称（如沿 z 轴拉长的椭球）一般出现电四极矩。电偶极子的分离在该方向上产生电四极矩。
- **电荷体系在外电场中的能量**：W=∫ρφe dV，对原点作多极展开后 W=Qφe(0)−p·Ee(0)+(1/6)D:∇∇φe(0)+…；各项分别为总电荷、电偶极矩、电四极矩与外场的耦合能。
- **电偶极子受外场的力与力矩**：F=∇(p·Ee)=p·∇Ee，L=p×Ee。

## 重要公式
- **麦克斯韦方程组（静电场部分）**： `∇×E = 0`，`∇·D = ρ`
- **电势与电场的关系**： `E = −∇φ`
- **两点电势差**： `φ(P₂) − φ(P₁) = −∫_{P₁}^{P₂} E·dl`
- **点电荷电势**： `φ(P) = Q/(4πε₀ r)`
- **多点电荷叠加电势**： `φ(P) = Σᵢ Qᵢ/(4πε₀ rᵢ)`
- **连续电荷分布的电势**： `φ(x) = ∫ ρ(x′)/(4πε₀ r) dV′`
- **泊松方程**： `∇²φ = −ρ/ε`
- **拉普拉斯方程**： `∇²φ = 0`
- **介质界面边值关系**： `φ₁ = φ₂`，`ε₁ ∂φ₁/∂n − ε₂ ∂φ₂/∂n = σ`
- **导体表面边界条件**： `φ = 常量`，`ε ∂φ/∂n = −σ`
- **静电场能量（场量表示）**： `W = ½ ∫ E·D dV`
- **静电场能量（电荷与电势表示）**： `W = ½ ∫ ρφ dV`
- **电荷分布自由能（互能）表示**： `W = 1/(8πε₀) ∫∫ ρ(x)ρ(x′)/r dV dV′`
- **导体球静电场能量（例）**： `W = Q²/(8πε₀ a)`
- **均匀电场电势（例1）**： `φ = φ₀ − E₀·x`，取 φ₀=0 时 `φ = −E₀·x`
- **无限长直导线电势（例2）**： `φ(R) = −τ/(2πε₀) ln(R/R₀)`
- **无限长直导线电场（例2）**： `E_R = −∂φ/∂R = τ/(2πε₀ R)`
- **导体表面受力面密度**〔蔡〕： `F = σ²/(2ε) ê`
- **有导体唯一性定理的电荷条件**： `−∮_{Sᵢ} ∂φ/∂n dS = Qᵢ/ε`，`φ|_{Sᵢ} = 常量`
- **唯一性定理证明积分**： `∮ε φ∇φ·dS = ∫ε (∇φ)² dV = 0 ⇒ ∇φ = 0`
- **球坐标拉普拉斯方程通解**： `φ(R,θ,φ) = Σ_{n,m}(aₙₘRⁿ + bₙₘ/R^{n+1})Pₙᵐ(cosθ)cos mφ + Σ(cₙₘRⁿ + dₙₘ/R^{n+1})Pₙᵐ(cosθ)sin mφ`
- **球坐标轴对称通解**： `φ = Σₙ(aₙRⁿ + bₙ/R^{n+1})Pₙ(cosθ)`
- **球对称通解**： `φ = a + b/R`
- **Legendre 多项式前几项**〔蔡〕： `P₀(x)=1, P₁(x)=x, P₂(x)=½(3x²−1), P₃(x)=½(5x³−3x)`
- **Legendre 函数正交性**〔蔡〕： `∫_{−1}^{1} Pₗ(cosθ)Pₗ′(cosθ) d(cosθ) = 2/(2l+1) δₗₗ′`
- **介质球在均匀外场中的电势**（例2）： `φ₁ = −E₀R cosθ + (ε−ε₀)/(ε+2ε₀) E₀R₀³ cosθ/R²`（球外），`φ₂ = −3ε₀/(ε+2ε₀) E₀R cosθ`（球内）
- **介质球诱导偶极矩**： `p = (ε−ε₀)/(ε+2ε₀) · 4πε₀R₀³ E₀`
- **接地导体球在均匀外场中的电势**（例3）： `φ = −E₀R cosθ + E₀R₀³ cosθ/R²`
- **接地导体球在均匀外场中的面电荷密度**： `σ = −ε₀ ∂φ/∂R|_{R=R₀} = 3ε₀E₀ cosθ`
- **导体尖劈本征指数**（例4）： `νₙ = n/(2 − α/π), n = 1,2,…`
- **导体尖劈端附近面电荷密度**： `σ ≈ −ε₀ν₁A₁ r^{ν₁−1}`，α 很小时 ν₁→½，σ∝1/√r（尖端放电）
- **柱坐标拉普拉斯方程**： `(1/r)∂/∂r(r∂φ/∂r) + (1/r²)∂²φ/∂θ² = 0`
- **柱坐标（与 z 无关）本征函数**〔蔡〕： `1, ln ρ, ρⁿ, ρ^{−n}（配合 sin nφ, cos nφ）`
- **柱坐标拉普拉斯方程通解**〔蔡〕： `φ = A₀ + B₀lnρ + Σₙ(Aₙρⁿ + Bₙρ^{−n})cos nφ + Σₙ(Cₙρⁿ + Dₙρ^{−n})sin nφ`
- **镜像法·接地平面导体板（例1）**： `φ(x,y,z) = 1/(4πε₀)[ Q/√(x²+y²+(z−a)²) − Q/√(x²+y²+(z+a)²) ]`
- **镜像法·接地导体球镜像电荷**（例2）： `b = R₀²/a`，`Q′ = −(R₀/a)Q`
- **镜像法·接地导体球外电势**（例2）： `φ = 1/(4πε₀)( Q/r − R₀Q/(a r′) )`
- **不接地导体球（带总电荷 Q₀）外电势**（例3）： `φ = 1/(4πε₀)( Q/r − R₀Q/(a r′) + (Q₀ + R₀Q/a)/R )`
- **点电荷 Q 在带电导体球上所受的力**（例3）： `F = 1/(4πε₀)[ Q Q₀/a² − Q²R₀³(2a²−R₀²)/(a³(a²−R₀²)²) ]`
- **两介质界面的镜像电荷**〔蔡〕：设两侧电容率为 ε₁、ε₂，则 `Q′ = (ε₁−ε₂)/(ε₁+ε₂) Q`，`Q″ = 2ε₂/(ε₁+ε₂) Q`（当 ε₂→∞ 时回到导体情形）
- **δ 函数定义与选择特性**： `∫_V δ(x)dV = 1`，`∫_V f(x)δ(x−x′)dV = f(x′)`
- **点电荷密度**： `ρ(x) = Qδ(x−x′)`
- **格林函数满足的方程**： `∇²G(x,x′) = −(1/ε₀)δ(x−x′)`
- **无界空间格林函数**： `G(x,x′) = 1/(4πε₀|x−x′|)`
- **上半空间第一类格林函数**： `G(x,x′) = 1/(4πε₀)[ 1/√((x−x′)²+(y−y′)²+(z−z′)²) − 1/√((x−x′)²+(y−y′)²+(z+z′)²) ]`
- **球外空间格林函数**： `G(x,x′) = 1/(4πε₀)[ 1/√(R²+R′²−2RR′cosα) − 1/√((RR′/R₀)²+R₀²−2RR′cosα) ]`
- **球坐标余弦关系**〔蔡〕： `cosα = cosθcosθ′ + sinθsinθ′cos(φ−φ′)`
- **格林公式**： `∫_V[ψ∇²φ − φ∇²ψ]dV = ∮_S(ψ ∂φ/∂n − φ ∂ψ/∂n)dS`
- **第一类边值问题的解**： `φ(x) = ∫_V G(x′,x)ρ(x′)dV′ − ε₀∮_S φ(x′) ∂G/∂n′(x′,x)dS′`
- **第二类边值问题的解**： `φ(x) = ∫_V G(x′,x)ρ(x′)dV′ + ε₀∮_S G(x′,x) ∂φ/∂n′(x′)dS′ + ⟨φ⟩_S`
- **第一类格林函数边界条件**： `G(x′,x)|_S = 0`
- **第二类格林函数边界条件**： `∂G/∂n′|_{x′∈S} = −1/(ε₀S)`
- **多极展开式**： `φ(x) = 1/(4πε₀)[ Q/R − p·∇(1/R) + (1/6)Σ_{i,j} Dᵢⱼ ∂²/∂xᵢ∂xⱼ(1/R) + … ]`
- **总电荷与电偶极矩**： `Q = ∫_V ρ(x′)dV′`，`p = ∫_V ρ(x′)x′dV′`
- **电偶极矩电势**： `φ^{(1)} = 1/(4πε₀) p·R/R³`
- **电偶极子（p=Ql）电势**： `φ ≈ −1/(4πε₀) p_z ∂/∂z(1/R)`
- **电四极矩（原始定义）**： `Dᵢⱼ = ∫_V 3xᵢ′xⱼ′ρ(x′)dV′`
- **电四极矩（约化定义）**： `Dᵢⱼ = ∫_V (3xᵢ′xⱼ′ − r′²δᵢⱼ)ρ(x′)dV′`
- **约化电四极矩的无迹条件**： `D₁₁ + D₂₂ + D₃₃ = 0`
- **电四极矩电势**： `φ^{(2)} = 1/(4πε₀) · (1/6)Σ_{i,j} Dᵢⱼ ∂²/∂xᵢ∂xⱼ(1/R)`
- **电四极矩并矢形式**： `φ^{(2)} = 1/(4πε₀) · (1/6) D:∇∇(1/R)`
- **一对反向偶极子的四极矩（例）**： `D₃₃ = 6Q(b²−a²) = 6pl`（p=Q(b−a)，l=b+a）
- **均匀带电旋转椭球的电四极矩**： `D₃₃ = (2/5)(a²−b²)Q`，`D₁₁ = D₂₂ = −(1/5)(a²−b²)Q`
- **均匀带电旋转椭球远处电势（至四极项）**： `φ = Q/(4πε₀)[ 1/R + (a²−b²)/10 · (3cos²θ−1)/R³ ]`
- **球谐多极展开**〔蔡〕： `1/|x−x′| = Σₗ Σₘ 4π/(2l+1) · R′ˡ/R^{l+1} Y*ₗₘ(θ′,φ′)Yₗₘ(θ,φ)`
- **多极矩（球谐形式）**〔蔡〕： `qₗₘ = ∫ R′ˡ Y*ₗₘ(θ′,φ′) ρ(x′) dV′`
- **电荷体系在外场中的能量**： `W = ∫ ρφₑ dV`
- **能量多极展开**： `W = Qφₑ(0) + p·∇φₑ(0) + (1/6)D:∇∇φₑ(0) + …`
- **偶极子在外场中的能量**： `W^{(1)} = p·∇φₑ = −p·Eₑ`
