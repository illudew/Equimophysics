# 教材解析与课后习题提取

把一本（或多本）教材读成两组东西：

1. **知识骨架**：章节 → 小节 → 概念 → 公式 → 推导，可与站点里已有章节逐条对照、补漏。
2. **课后习题库**：题号、题干、所求量、答案要点、教材页码，可直接归入章节。

不负责站点渲染与课程接入——那部分走 `nku-exam-site`。

## 何时触发

- 用户上传教材 PDF/DOCX，说「校对」「补充」「这章内容不全」「提取课后习题」。
- 已有课程章节需要回填教材定义、公式或例题。
- 需要把教材习题整理成可检索、可回溯的题库。

## 红线（覆盖一切流程）

1. **不编造**：题干、数值、选项、答案、页码，任一缺失就写「原书未给出 / 此处为公式图片」，不许用常识补齐。
2. **可回溯**：每道题带 `page`（PDF 物理页）与 `no`（原书题号）；每个概念/公式带来源小节号。
3. **不改写题意**：只做 OCR 纠错、符号统一（如 `×` `/` 规范）、公式转 LaTeX；措辞保持原样。
4. **答案分级**：教材有答案 → `key` 照录并标「原书答案」；只有提示 → 标「原书提示」；都没有 → 写推导思路并标「推导待核」，不得标成标准答案。
5. **存疑即删**：原书答案与物理推导矛盾且无法判定时，整题删除并在交付说明里列出，不猜。

## 阶段 0：资料盘点

先确认文件真的落盘（上传常失败）：

```bash
ls -la .uploads/ | tail -20
find . -maxdepth 3 -iname "*教材*" -o -iname "*textbook*"
```

按文件给出「页数 / 文本字符 / 图片数」三列，`text≈0 且 imgs>0` 判为扫描件。

| 类型 | 判定 | 处理 |
|---|---|---|
| 文本型 PDF | 每页字符 > 200 | 直接提文本，公式按上下文转 LaTeX |
| 排版型 PDF（双栏/公式多） | 文本提取乱序 | 按栏切分或逐页读图校对 |
| 扫描件 | 字符 ≈ 0 | 渲染 PNG 后 OCR，质量不足转人工转写 |
| 教材习题册 | 题号连续 | 按题号切块，独立成库 |

## 阶段 1：文本与版面提取

```python
import pymupdf

def pdf_pages(f):
    doc = pymupdf.open(f)
    for i, p in enumerate(doc):
        yield i + 1, p.get_text(), len(p.get_images())
```

要点：

- **保留页号**：后面所有引用都靠它，别把页边界丢掉。
- **双栏**：`p.get_text('blocks')` 取 `bbox`，`x0 < 页宽/2` 归左栏，否则右栏，再各自按 `y0` 排序。
- **页眉页脚**：整页重复出现的短行（书名、章名、页码）先统计频次再去掉，避免污染题干。
- **公式**：文本层里的公式常被拆成单字符碎片。判据是「连续短 token + 含 `= ∑ ∫ √`」。这类位置标记 `[公式图 p{n}]`，读图补。

扫描件转图：

```python
doc = pymupdf.open(f)
for i, p in enumerate(doc):
    p.get_pixmap(dpi=200).save(f"img/{tag}_p{i+1}.png")
```

`dpi=200` 是公式可读的下限；`150` 只够读正文。

## 阶段 2：章节与小节对齐

1. 用目录页建立「章 → 起始页」，再按正文标题校验（目录页码常有偏移）。
2. 章号取**原书编号**（`第1章` / `1` / `Chapter 1` / `§1.2` 都保留原样），不要重排成 1..N。
3. 与站点章节表对齐时输出一张对照表，标出三种差异：
   - `站点有、教材无` → 可能是讲义补充内容，保留并注明来源。
   - `教材有、站点无` → 待补章节。
   - `同名但小节不同` → 逐小节列出缺哪几条。
4. **对齐以教材目录为准**，站点结构服从教材；用户另行指定章节划分时以用户为准。

## 阶段 3：知识骨架提炼

每个小节产出四类条目，宁少勿滥：

| 字段 | 要求 | 反例 |
|---|---|---|
| 概念 | 一句话，含定义的必要条件 | 「熵是混乱度」（不完整） |
| 公式 | 符号表 + 适用条件 | 只给式子不写条件 |
| 推导 | 3–6 步，起点 → 关键一步 → 结论 | 把教材整段抄成一段 |
| 易错点 | 只在教材明确强调时记 | 自行发挥 |

公式转写规范：

- 单字母下标不加括号，多字母下标加：`C_V`、`C_{p,m}`。
- 矢量用 `\vec{}`，单位矢量用 `\hat{}`；不要用粗体假装矢量。
- `\frac` 嵌套不超过两层，深层改写成 `/`。
- 每个公式配一句「什么时候能用」，写在公式名里而不是正文里。
- 教材用 `ln`/`lg`/`log` 混用时保留原写法，并在符号表注明底数。

推导选取优先级：教材正文有完整推导 > 例题里的关键一步 > 习题答案里的解法。**教材没推导的不要自己造一条塞进去**。

## 阶段 4：课后习题提取

### 4.1 切题

用题号正则切块，兼容常见格式：

```python
import re
PAT = re.compile(r'^\s*(?:习题|练习|思考题)?\s*(\d{1,3})\s*[.．、]\s*', re.M)
```

- 先按「习题 / Exercises / Problems」标题定位习题区，避免把正文编号误判成题号。
- 跨页题：题号在页底、选项在次页顶，按 `no` 合并，`page` 记起始页。
- 一题多问（(1)(2)(3)）：作为同一题的 `parts`，不要拆成多题。
- 题号跳号：记录缺失题号，交付时说明「原书跳过 N 题」，不要重编号。

### 4.2 解析

```js
{
  no:'4-7',                    // 原书题号，含章前缀
  page:126,                    // PDF 物理页
  stem:'…题干原文…',            // 公式用 $...$
  ask:'求什么',                 // 题干未明说时从上下文提取
  type:'计算',                  // 计算/证明/简答/选择/填空
  key:'…',                     // 答案或推导要点
  keySrc:'原书答案' | '原书提示' | '推导待核',
  ch:'第4章'
}
```

- 选择题把选项拆成数组，`answer` 单列；OCR 常把 `A.` 和正文粘连（`A y 气体的…`），必须逐题核对选项个数是否等于 A–D。
- 图题（「如图所示」）：导出该页 PNG 裁切配图，路径写进 `fig`。图缺失时题干保留「如图所示」并在 `key` 注明「图缺失，按文字条件不可解」。
- 数值题保留原书有效数字与单位，不做单位换算。

### 4.3 答案处理

1. 教材附答案 → 照录，标 `原书答案`。
2. 只有最终数值 → `key` 写「原书答案：x」，推导思路另起一行标「推导待核」。
3. 答案与物理推导冲突 → 先查单位、符号约定、近似条件；仍冲突则**删题**并登记。
4. 证明题 → `key` 写证明主线三步，不写完整演算。

### 4.4 质量抽检

抽 10%（至少 10 题）做四项检查：

- 题号在教材中真实存在，页码对得上；
- 题干无 OCR 粘连、无公式残片；
- 答案出处标注与实际情况一致；
- 选择题选项数 = 4（或原书实际值）。

任何一项不过，回到 4.2 重解该批，不要单题打补丁。

## 阶段 5：校验

```bash
# 1) 题号连续性：缺失清单 + 重复清单
# 2) 页码单调：同章内 page 应随 no 递增
# 3) 覆盖率：已提取题数 / 正文题号总数
# 4) 字符守恒（若与原文对照）：只允许删页眉页脚与页码
```

```python
nums = sorted(int(q['no'].split('-')[-1]) for q in bank)
missing = [n for n in range(nums[0], nums[-1]+1) if n not in nums]
dups = [n for n in set(nums) if nums.count(n) > 1]
print('miss', missing, 'dup', dups, 'cover', len(nums))
```

验收：`dup` 为空；`miss` 每条都有书面原因；`cover ≥ 90%`。
交付时随机回读 3 页原 PDF 对照，确认题干未被顺手改写。

## 交付格式

1. 一句话：处理了哪几本教材、覆盖几章、提取几题。
2. 对照表：章节缺口（站点有/无 × 教材有/无）。
3. 习题统计：题数、题型分布、答案来源分布（原书答案 / 提示 / 待核）。
4. 问题清单：删了哪几题、为什么；哪些图缺失；哪些公式是图、未转写。
5. 与站点对接：给出可直接插入的 `XX_CHAPTERS` / `XX_EXAMS` 片段字段映射，不直接改站点文件（改站点走 `nku-exam-site`）。

## 常见坑

- **上传文件不存在**：先 `ls .uploads/`，找不到就直接告知用户重新上传，不要开工。
- **OCR 冒充成功**：批量 OCR 出 80% 可读也不要用；题干粘连会导致整库不可信，宁可少收 10 题人工转写。
- **公式全失**：扫描件公式必丢，凡是含公式的题一律读图，不看 OCR。
- **题号重排**：教材跳号是有意的（删题/合并），重排会让用户回查失败。
- **把例题当习题**：例题有完整解答，习题区才是题库；两者分开放，例题可作 `key` 参考但标明出处。
- **多版本教材混用**：不同版次页码不同，先确认版次并把 `textbook` 写进数据，别跨版引用页码。
